## 1. 整页结构与首屏

基础阅读顺序：系统/导航 → 驾驶舱切换与组织搜索 → 当前组织及平级组织 → 项目信息 → 重点信息条 → 业务卡片组 → 底部导航。

扩展版可增加问候语、本周登录次数、报告入口；地区/大项目页可省略项目基本信息和部分项目级指标。依据角色与版本选择，不把所有模块拼满每个主页。

| 区域 | 已读样本 | 规则 |
|---|---|---|
| 系统及导航 | 88高=状态栏44+导航44，标题“一看” | 适配真实设备与宿主，避免重复系统区 |
| 操作区 | 驾驶舱96×36、搜索36×36、报告约60×36，局部gap8 | 权限入口隐藏后补位 |
| 组织区 | 左侧固定当前项，右侧同级组织条 | 不用普通均分Tabs替代组织切换逻辑 |
| 项目信息 | 343×46，项目来源/建筑面积/收费标准三列 | 是组织背景信息，整块进入项目详情 |
| 重点信息条 | 343×40，图标+主营收费率+箭头 | 整块进入重点信息详情；阈值不能按颜色猜 |
| 指标列表 | 两侧16，常见343宽，卡间常见16 | 按主营、财经、增值等业务分组，不按一个值拆一张卡 |
| 底部导航 | 首页/指标/我的；主页选中 | 主组件key `2715f0ffb527b6fafd3213f5449e1fa56c428c9e` |

卡片起点y约230/332/337/367，取决于头部模块，不是固定页面坐标。1243/1351/1626为长内容样本高度，不是设备屏高。底栏样本中68高Tab Bar与34高Home Indicator重叠组成82高；不要机械相加，也不把源稿负gap直接当生产实现规则。

### 主页离线组装

用 `screen.homeHeader` 配置组织，用 `screen.homeProfiles` 按组织 ID 提供页面内容。每份内容可配置 `project{origin,area,fee}`、`highlight{label,value}` 和 `cards[{type,props}]`。切换组织时三块内容从同一组织读取。无资料时省略项目资料区，无指标时显示空态。HTML 内嵌数据，输入仅包含当前读者可见的组织资料。[项目主页样例](../assets/offline/项目主页-离线交互.html)

## 2. 五类卡片，按业务关系选择

| 类型 | 来源 | 卡内结构 | 适用条件 |
|---|---|---|---|
| 单指标摘要卡 | 满意度 `4424:66104`，以及利润率、充电流水、GMV等 | 左侧名称+更新时间；右侧主值/单位，上值下同环比 | 单指标可独立理解 |
| 主指标+三子指标卡 | 实收 `4424:66070` | 主金额摘要 → 虚线 → 收费率、预存、期末欠费三列；每列保留自己的同环比 | 一个业务组需同时扫读主值和支撑项；三项不是天然构成关系 |
| 双指标合并卡 | 电梯/停车 `4424:66115` | 两个摘要行上下排列，虚线分隔，各有名称、日期、单位及同环比 | 原项目有明确组合；不要求两指标共用分母或单位 |
| 指标+解释项卡 | 税前利润率 `4424:72991` | 主率值与双比较 → 浅青解释区列税前利润(权责)、经营性收入(权责) | 比率需要基础金额解释；算式需按指标定义 |
| 多段目标复合卡 | 现金流 `4424:72760` | 当月净额 → 半年达成率/累计净额/目标 → 年达成率及参照；虚线分段 | 多期间、多目标信息须保留在一个完整业务组内 |

主页已读卡片主要以数值、同环比、解释项表达。不能规定每张主页卡都放环图；趋势、构成、目标图按实际问题及数据选择，也不能因为主页是数字卡就让详情页一律没有图。

“微信代扣签约率”与“已收楼代扣签约率”来自不同样本，名称与口径不能自行合并。新增业务允许增加卡片，不要求所有版本固定数量或顺序。

### 本批原稿的主页经营卡

`homePerformanceCard` 对应经营性收入 6671:164095、税前利润金额 6671:164148、现金流净额 6671:164196。其中税前利润为金额卡，与 4424:72991 的税前利润率解释卡分别适用。经营性收入复用原稿的渐变曲面；收入与利润的完成率由业务明确传入，与同比独立。超出 0–100% 时保留真实读数，进度条只用 0–100% 表示。现金流卡分别输入目标缺口、同比金额变动及各自单位。[离线核对](../assets/offline/主页经营卡-离线核对.html)

`homeProfitExplanation` 对应 `4424:72991`。主行展示税前利润率和各自的同比、环比，浅青解释区保留税前利润（权责）与经营性收入（权责）两行。使用已确认统计口径的 `rate`，两笔权责金额的期间、范围及单位应一致。同环比各自传入，零值正常展示，缺失主值或金额显示「—」。[离线核对](../assets/offline/主页经营卡-离线核对.html)

`homeCashflowTargets` 对应 `4424:72760` 的现金流多段目标卡。原稿保留紫色光晕、两道虚线和两块浅青解释区。上段为当月净额，另两段分别展示半年度与年度达成率、各自的累计净额和目标。三段的同比标签绑定同期间金额差 `yoyDelta`，带金额单位。达成率由业务输入，可为负数、零或超出 100%。年度解释区以年度数据绑定，原稿重复的半年标签及无效金额占位见下文。[离线核对](../assets/offline/主页经营卡-离线核对.html)

## 3. 卡片外观与布局实测

上述主要卡片为业务 **FRAME**，内部含同环比等原生实例，不是全部已发布为卡片主组件。复用完整业务组合，再适配字段和空间；不能只用了图标就宣称复用卡片。

| 属性 | 样本实测 | 注意 |
|---|---|---|
| 宽度 | 常见343；部分单卡342但内层仍311 | 源稿有1px不一致，不当作两个正式断点 |
| 内边距 | 四边16，常见内容311宽 | 不是每个嵌套层再加16 |
| 圆角 | 卡12、解释区4、重点条6、操作按钮胶囊 | 不把全页所有形状统一为12 |
| 填充 | 白色paint opacity约0.60 | 是填充透明度，不是整卡opacity；数字/文字保持原透明度 |
| 描边 | 白色2，OUTSIDE | 与详情实白无描边卡分开 |
| 阴影 | (0,2)，blur约10.9，spread0；原浮点RGB约(0.38585,0.58644,0.58644)，alpha0.12 | 不替换成通用重投影 |
| 光晕 | 117×117绝对定位椭圆，blur约90.4，卡片左上外侧，clipsContent=true | 装饰不占内容布局，不压住读数 |
| 光晕色 | 主营蓝约#56B8FF、财经紫#949CF8、增值青#33C1C1 | 是业务分组视觉，不是风险灯号 |
| 虚线 | 青约#00B2B2，stroke1，paint opacity0.30，dash[5,4] | 分隔模块，不表示同期曲线 |
| 解释区 | 主色青fill opacity0.08，上下6/左右8 | 只包解释内容，不把整个复合卡再染青 |

单值卡92≈上下16+主行60；双摘要176、实收178、利润率解释156、现金流388，是内容下的样本尺寸，不能规定为全部同类卡固定高度。

主行常用横向SPACE_BETWEEN：左组左对齐，右组主值和同环比右对齐；右组gap4，左名称/日期样本gap10并有顶部3的光学微调。主值与单位对齐基线。实收三子指标样本列宽93、列间16，共311宽，每列为名称→值与单位→小号同环比。

## 5. 背景和资源

源`4424:66054`为多层青/蓝渐变、柔光、局部浅粉、半透明曲面的组合；包含blur30/54的背景层，与卡内blur90.4光晕区分。精确渐变stop、transform、透明度与effects保留在证据JSON中，不把复杂背景猜成两个HEX端点。

右上品牌形象为独立图像资源，已有资源可用时复用，不用通用图标或随意新造角色替代。它属于品牌装饰，不是业务数据编码，也不要求每张卡都放。长页背景覆盖实际内容，不把整张截图拉伸为UI底图。

主页半透明卡必须连同实际背景检查对比；详情页#F3F8F8+实白卡是另一类页面，不自动互换。

## 6. 交互与权限：原稿明文

来自`4424:67767 / 67770 / 67789 / 67792 / 67795 / 67798`：

- 搜索按钮实际打开组织选择器，承担组织切换，不是全局关键词搜索。
- 多组织范围由用户最高权限组织层级决定；当前组织固定在左，右侧平级组织可横滑。选中项移到左，原项回到右侧原顺序位置，其余项不重排。
- 名称定宽超长省略；从上级通过搜索选择下级后，只显示当前组织，不显示右侧同级项；单组织不保留空的切换轨道。
- 驾驶舱/一看按钮写即将切换的目标名称；角色决定默认进入哪个看板。无驾驶舱权限则隐藏，右侧控件左移补位。
- 项目信息、重点信息整块进入对应详情；指标按说明框选区域进入各自详情。复合卡需保留各指标点击区，不能全部跳向同一个未定义页面。
- 本轮抽查源节点`reactions=[]`，上述为文档交互要求，不是已连好、已测试的可运行原型。

## 7. 时间与数据状态

原稿框架写：首页普通指标按最新年累计显示，当月无数据时向前找最近有数据月份；例如12月无数、11月有数，则显示累计到11月。更新时间要与实际展示数据对应，不能显示为当前月、不能将未更新当0。

现金流新增卡写“当月净额”、半年及年度达成率，是不同期间的例外。使用具体指标生效定义，不能让年累计通用说明覆盖全部新增业务。

空数据页`4424:66707`仅对部分主值显示“-”，其他有数据的指标继续显示，不是整页清空。但缺失主值旁还留有3.23%涨跌标签，属于源稿未解释的一致性问题。核对比较值是否独立有效，不抄占位增长；真实0、缺失与无权限分开处理。

## 8. 不升级为规范的源稿问题

1. 利润率/总成本页`4424:72977`背景x=-368，截图大面积空白、图形裁切，不能推导为新的白底主页主题。
2. 现金流占位字符串`138.323.09万`有两个小数点；年度段仍留“半年度目标”等标签，不作为数字格式或正式字段依据。
3. “总成本”有%示例，其他版本“主营总成本”是金额；需核对指标，不静默改单位。
4. 长页底部导航覆盖最后卡片部分内容。实现要预留可滚动底部空间，不能用源截图遮挡来证明可交付。
5. 源稿有绝对定位与硬宽值；长名称、长值需语义分组和自动布局适配，保留视觉关系，不把坐标当作通用规则。

复核顺序：角色/组织 → 头部模块 → 业务卡类型 → 主子指标与同环比 → 时间/缺失 → 主页专用样式 → 首屏及全页 → 点击区与底部遮挡。静态读取、视觉复核、真实交互和用户验收分别记录。
