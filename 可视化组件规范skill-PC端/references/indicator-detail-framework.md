## 何时使用

设计单个指标详情，或多个指标切换共用详情结构时，默认从本框架开始。用户说“指标详情框架”“指标详情模板”“按详情页结构做”时直接读取本文件及视觉参考。用户明确指定其他布局时，以其要求为准。

首页、多个独立业务模块的经营概览和密集财务报表，先按[页面模式](page-patterns.md)确认任务，不因为页面有数字就强套本框架。

## 整页骨架与职责

```text
导航及日期筛选
指标上下文与摘要（同一连续顶部区域）
  指标切换 → 数据分类 → 指标名称/释义/时效
  主值与单位 + 各自同比/环比 → AI解读入口
分析白卡
  分析维度Tabs → 当前图表 → 对应分类/时点明细
排名卡
  排名标题/说明/展开 → 本项目所在范围与自身排名
  所在范围排名表 → 分隔 → 下辖范围选择及排名表
底部安全区
```

该框架传达的是“先理解当前指标，再分析构成/变化，最后比较组织”的阅读顺序。顶部指标切换、数据分类、分析维度、排名范围是不同层级，分别控制各自内容。

## 按业务替换的顺序

1. 先把需求字段映射到上面各槽位，确定主指标、期间、范围与分析任务。
2. 复用源顶部与分析/排名组合的视觉关系；清除“指标一”“数据一”等占位，并配置实际名称、日期、单位、比较值和释义。指标或分类仅一项时按业务隐藏对应切换并回收空间。
3. 为每个分析维度选择图表，沿用“Tabs—图形—精确明细”关系：构成用同一整体分类；趋势用真实时间序列；进度用实际与目标；独立比率保留各自分母。缺少某分析所需数据时标明缺口，不用模板曲线或占比冒充业务值。
4. 按组织权限配置所在范围与下辖排名。没有排名需求或权限时，记录原因并省略；不补造组织、名次或姓名。已有排名字段必须保留到适当位置。
5. 在375×812参考首屏及完整长页检查主次。该模板的分析明细和排名位于滚动后；内容需要更多空间时调整分组、Tabs和图文组合，不通过全页缩字解决。

## 重要表达与交互边界

- 顶部主值负责概览；图心与下方明细负责当前分析读数。只有业务对象和读取职责相同才考虑去重，不能机械删掉环心或摘要。
- 日期、指标、分类变化时，名称、主值、时效、比较、图形和排名应指向同一有效上下文。各Tab的具体联动按实际指标定义，不从静态样例推断已实现。
- 同比/环比可为百分比或金额差，分别处理单位、方向和比较期。模板的两种标签不是每个指标必须同时出现。
- AI解读按业务条件提供；无实际解读数据时，不复制源“XX区域”等占位结论。历史锁数提醒仅在适用指标及查询状态出现，不能因为欠费实例有提醒就强加到全部页面。
- 排名权限、同级脱敏与下钻、下辖范围、搜索、排序和宽表边缘阴影，读取[组件06](components.md)。截图里隐藏在右侧的列仍需可达，不将截图裁切当成字段删除许可。
- 字体、颜色、同环比和图表专用几何继续使用对应参考文件。源渐变的stop、transform和透明度优先复用已有实例，不用通用白卡覆盖顶部和排名主题。

## 占位与源稿疑点

模板主值82.2万、图心679.00万、六分类金额与百分比、排名52/77和示例姓名均为占位内容，不是可迁移的业务数据。六分类占比合计99.99%，不能由此规定真实构成必须不满100%；图心、摘要和明细金额也没有被证实属于同一整体。图中多色环与下方重复同色点不直接作为新业务的图例规则，应保持新业务分类—图形—明细同色对应。

2026-10-27新增的是本模板的结构与视觉基准收录，不代表源稿所有字段、隐藏状态和交互已经核验。截图及节点读取不证明可点击原型；新交付仍应分别报告结构、视觉、交互、字体替代与用户验收状态。
