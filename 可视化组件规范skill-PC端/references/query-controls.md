## 日期组件合同

`dateControl({value,years,granularities,min,max,today,picker,dataPeriods})`。完整字段为`{granularity:'year'|'month'|'day',year,month,day}`，即使显示年/月仍保存月日以便切换；初始非法日期直接报错，不把2025年2月29日当有效日期。

`years`是明确可选年份。未配置时只提供围绕初值的9年本地演示窗口，这不是产品历史数据范围。`min/max`为显式日期边界，未配置不自行宣称未来禁用或最早日期；按年/月比较时按相应粒度比较边界。初值必须可选，反向边界报错。

原稿明确确认后粒度同步、快捷周期查看本年/月/日。SDK增加以下本地实现约定：打开复制已提交值为草稿；改年/月后将超出的日夹到该月最后一天；点确定才提交；取消/Esc丢弃草稿；关闭恢复入口焦点。原稿未完整规定取消策略，因此这些是明确实施合同，不能引用为源稿原句。

快捷年度/月度/按日使用运行设备当前日期；跑测通过`today`固定。若当前日期超出配置范围，不静默改到别的年份，发出`yikan:queryerror`。日期文案不补零。

底部选择区域使用可点击、可滚动的列，保留原始尺寸与字体层级；支持滚动停止后吸附到离中心最近的可选项，并写入草稿，确认后才提交。滚动吸附在支持 `scrollend` 的浏览器启用；点选仍可使用。真机惯性手势仍待单独核对。

## 完整日历页

当流程需要独立的日期选择页时，设 `picker:"calendar"`。当前粒度决定打开哪一页。年度三列、月份每年四列、按日为周一至周日七列，分别复用 6671:132304、6671:132073、6671:132460 的页面结构与三种视图图标。月份跨年滚动，按日在当前浏览年内滚动，并用年份选择跨年。月末夹日与可选范围继续使用共用日期逻辑。

完整页点中有效日期立即提交，返回或 Esc 保留已提交日期。这个行为按原稿未设置确认按钮的界面定义为本地交互。底部「回到本年／本月／本日」提交当前粒度对应日期。当前日期超出允许范围时，按钮不可用。

点位由 `dataPeriods` 显式提供，列表成员沿用完整日期字段。以成员的粒度、年、月、日匹配可用位置，有数据时展示圆点并提供读屏提示。数据可用标记、可选范围和当前选中状态独立。可参考 [离线交互三个状态](../assets/offline/完整日历-离线交互.html)。

按日的浏览年份选择和短屏选中项定位是本地适配。月视图说明采用「当月每日累计值」，原稿写作「当日每日累计值」。离线页沿用页面宿主的实际安全区，不绘制示意系统状态栏。

## 组织组件合同

`organizationControl({nodes,value})`。每条记录包含`{id,name,parentId,selectable,level}`；`selectable`必须明确为布尔值。ID重复、孤立父节点、循环、初值不可选均报错。

输入须是业务已允许展示的组织与路径节点。不可选上级可作为显式路径传入，`selectable:false`表示可浏览路径但不能作为查询对象；不应传入本不允许用户看到的组织。前端可选状态不能替代服务端鉴权。

SDK不自动构造“全部区域/全部地区”越权聚合。需要聚合时由需求提供明确的聚合节点与授权语义。搜索仅查输入节点；没有结果显示暂无匹配。当前实现约定：分支进入下一级，授权可选分支提供选择本级，叶子立即提交，取消/Esc保留原值。这不是所有历史布局的唯一交互定义。

完整权限角色矩阵、附近/定位、组织下载和真实数据下钻未在本模板实现。不要把一个本地过滤列表说成完整组织权限系统。

## 页面接入

`build_page.py`已内嵌`query-controls.js`，无需Figma或网络。手工拼接页面时需先加载assets.js、native-rings.js、query-controls.js，再加载yikan.js。

提交后发出冒泡事件：

```js
document.addEventListener('yikan:datechange',e=>{
  // e.detail.value为已提交的粒度与日期，按页面查询合同刷新数据。
});
document.addEventListener('yikan:organizationchange',e=>{
  // e.detail.value为明确可选节点，e.detail.path为其路径。
});
```

控件之间不擅自改变彼此查询口径；日期和组织事件不等于全页图表/排名已刷新。页面需要明确数据表、查询映射与加载/失败状态后接通。
