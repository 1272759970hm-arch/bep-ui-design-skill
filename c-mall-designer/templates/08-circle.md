# 08 圈子（内容 / 社区）

**画板**：圈子（375×2568）、好货预告模块（Frame 1321320530，439×721）
**可运行代码**：无（长内容流，用 `tpl-home.js` 的商品卡 + 自组合动态卡）

> 与首页的区别：内容主体是**门店动态流**，商品卡作为动态的附件出现。

## 区块顺序

| # | 区块 | 参考 y / 高 | 内容 | 组件 |
|---|---|---|---|---|
| 1 | 门店圈头图 | 0 / ~300 | 门店名「华南碧桂园」+ 关注按钮 + 渐变 | `mkImage` + 遮罩 |
| 2 | 门店分类横滑 | ~300 / 56 | 健身房 / 咖啡店 / 奶茶店 / 教培店 / 料理店 / 电影院 / 面包店 / 餐饮店 | chip 横滑（未选款） |

## 好货预告模块（可单独复用）

| 区块 | 内容 |
|---|---|
| 模块头 | 「好货预告」+ 右侧「查看全部 ›」 |
| 横向卡列 | 每卡 140 宽：商品图 + 名称 2 行 + 「开抢提醒」小按钮（outline，64×24） |
| 用法 | 可嵌在首页营销位、详情页底部、圈子流中；作为**独立区块**，不装白卡 |

## 易错点

- 动态正文用 `mkTW`，行高 22，最多 4 行后折叠
- 图片宫格：1 图 → 4:3 大图；2–3 图 → 三等分方图；4+ → 3 列方图网格，gap 4
- 下单提示条是**浮层**（贴在流上方，`C.white` + 85% 不透明），不要挤进内容流
- 「圈子」tab 在底部标签栏里是 4 个 tab 之一，切换高亮不要重排
