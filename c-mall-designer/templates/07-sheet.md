# 07 底部弹层（购买弹窗 / 加购面板）

**画板**：购买弹窗（375×812）、加购 ×3（375×812）
**可运行代码**：`tpl-sheet.js`

## 结构（底色遮罩 + 底部白卡）

```
screen 812
├─ 背景页面（模糊/压暗 40% 黑）
├─ backdrop（375×812，rgba(0,0,0,.4)）  ← 点击关闭
└─ sheet（贴底，圆角上 16，白底）
   ├─ 商品摘要行（图 88 + 价格 + 已选规格 + ×关闭）
   ├─ 规格区（标题「规格」+ chip 组）
   ├─ 数量区（标题「数量」+ 步进器，右对齐）
   └─ 确认按钮（描边橙「加入购物车」/ 通栏「立即支付 ¥399」）
```

## 购买弹窗（y=512，高 300）

| 区块 | 内容 | 规格 |
|---|---|---|
| 商品摘要 | 缩略图 88×88（圆角 8）+ 价 `¥35.5`（大步阶橙）+ 「预估佣金」**双段胶囊** `mkDuoTag` + 已选「单瓶装」 | 高 ≈ 112 |
| 关闭 | 右上 ×，热区 32×32 | 图标 14–16 |
| 规格 | chip：「单瓶装 / 双瓶礼盒 / 宴请整箱」，选中描边橙 | registry §4.3，h34 r18 |
| 动作 | 「加入购物车」106×40 outline | registry §4.1 |

## 加购面板（全屏 812，y=0）

| 区块 | 内容 | 规格 |
|---|---|---|
| 顶部 | 返回 + 标题 + 关闭 | 90 顶栏 |
| 商品 + 规格 | 同购买弹窗，但展开显示全部 SKU 与库存 | — |
| 配送方式 | 分段控件「送货上门 / 到店自提」 | registry §4.5 |
| 底部 Footer | **通栏「立即支付 ¥399」351×44** | registry §4.2 |

## 易错点

- sheet 的圆角只在**上两角**（`topLeftRadius` / `topRightRadius = 16`），四角全圆是错的
- 遮罩必须独立于 sheet 且在下层；sheet 内不要用 `clipsContent=false`
- 关闭按钮在**摘要行右上角**，不要在标题栏
- 未选规格时确认按钮置灰（`C.disabled` 底 + 白字），且不允许点「立即支付」
- 加购面板的支付按钮是**通栏 351**，不是 106 的次按钮；别和详情页双按钮混用
