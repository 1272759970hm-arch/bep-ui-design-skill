一条硬规则：同一屏里标签最多出现 2 种语义色（一个主状态 + 一个优先级/分类）。三种以上颜色混排会让列表看起来像"仪表盘报警墙"。

07反例（这四种以前都犯过）

下面每个都是错的，旁边写了为什么。看见类似形态直接判错。

X-01
进行中
底色 16% —— 太重。标签在页面里是"轻标记"，16% 的底会跟卡片本身抢注意力，看着发闷发糊。标签只能是 10%；16% 是胶囊 Tab 二级选中态的档位。
X-02
未开始
中性用灰底黑字 —— 太实。#F2F3F5 + #444F60 的观感是"禁用按钮"，不是标签。中性必须用石板灰 10% 底 rgba(111,135,158,.10) + #6F879E 字。
X-03
待响应
底字不同源 —— 色相打架。底是 255,166,69（暖橙），字是 255,125,0（正橙），叠在一起像"一个标签里放了两种黄"。字必须取底的同色相实色 #FFA645。
X-04
已超时
四角统一小圆角 —— 像贴纸。角标只在右上 + 左下两角给 8px 圆角（0 8px 0 8px），才能"嵌"进卡片角落。四角都给 2px 会像贴在卡片外面的便利贴。

08可直接复制的 CSS

颜色全部走 CSS 变量，页面里不要出现裸色值。

/* ---- 变量：底 10% + 同源实色字 ---- */
:root{
  --tag-brand-bg:rgba(0,177,180,.10);    --tag-brand-text:#00B1B4;
  --tag-success-bg:rgba(0,180,42,.10);   --tag-success-text:#00B42A;
  --tag-warning-bg:rgba(255,166,69,.10); --tag-warning-text:#FFA645;
  --tag-danger-bg:rgba(245,63,63,.10);   --tag-danger-text:#F53F3F;
  --tag-neutral-bg:rgba(111,135,158,.10);--tag-neutral-text:#6F879E;
  --r-card:8px; --r-tag:2px;
}

/* ---- 行内标签：默认小档 20px / 12px ---- */
.tag{
  display:inline-flex; align-items:center; justify-content:center;
  height:20px; padding:2px 8px; border-radius:var(--r-tag);
  font-size:12px; line-height:1; white-space:nowrap;
}
/* 大档：跟标题同行时用 */
.tag.lg{ height:22px; font-size:14px; }

.tag-brand  {background:var(--tag-brand-bg);  color:var(--tag-brand-text)}
.tag-success{background:var(--tag-success-bg);color:var(--tag-success-text)}
.tag-warning{background:var(--tag-warning-bg);color:var(--tag-warning-text)}
.tag-danger {background:var(--tag-danger-bg); color:var(--tag-danger-text)}
.tag-neutral{background:var(--tag-neutral-bg);color:var(--tag-neutral-text)}

/* ---- 卡片状态角标：贴右上角，只在右上+左下给圆角 ---- */
.tag-badge{
  position:absolute; top:0; right:0;
  height:27px; padding:4px 8px;
  border-radius:0 var(--r-card) 0 var(--r-card);
  font-size:12px; line-height:1;
  display:inline-flex; align-items:center; white-space:nowrap;
}
/* 父卡片必须 position:relative，且 overflow:hidden 或自身圆角 >= 8px */

09交付前 6 条自检

写完页面照着念一遍，全过再发出去。

C1所有标签底色都是 10%？搜一遍代码里有没有 .16 被用在标签上。
C2每档的底和字同源？橙底配橙字、红底配红字，不能跨色相。
C3中性标签是 rgba(111,135,158,.10) + #6F879E？不是 #F2F3F5 灰底黑字。
C4角标圆角是 0 8px 0 8px、高 27、贴右上角？父卡片加了 position:relative？
C5同一屏里语义色 ≤ 2 种？超过就是报警墙。
C6标签都是不可点的？能点的应该是胶囊（chip），别给标签加 hover 和 cursor:pointer。
