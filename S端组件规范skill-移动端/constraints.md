# BEP-S 可执行约束表

> 本文件把散落在各处的规则收敛成**逐条可勾选的检查项**。交付前按此表过一遍，不通过的必须改到通过或显式声明例外。
> 每条标注来源与严重级别：`P0` = 违反即重做；`P1` = 必须修正；`P2` = 建议修正。

---

## 0. 冲突裁决优先级

当"规范文档 / 画板注释 / 组件实现 / 用户指令"互相打架时，按此顺序取值：

```
P(-1) 用户在对话中的直接指令（USER_OVERRIDE，最高）
P0    真实组件的当前实现（画板里实际长什么样）
P1    组件 Variant / Properties
P2    组件内部自带的 Token（字号/颜色）
P3    全局 Design Token（design-tokens.md）
P4    页面级规范（mobile-ui-rules.md / page-patterns.md）
P5    通用移动端经验（最低，只用于库内确实没有的场景）
```

**已知冲突清单**（不要再重新调查，直接引用结论）：

| 冲突点 | 文档说法 | 组件实现 | 采用 | 理由 |
|---|---|---|---|---|
| 底部导航高度 | 间距画板注释 56px | 375×50（678）/ 375×84（X） | **50 / 84** | P0 组件实现优先 |
| 页面标题字号 | Token 24px | NavBar 内置 18px | **18px**（NavBar 内） | P0，且不改组件 |
| 行高比例 | 画板注释"1.5倍" | 图层 lineHeight 140% | **×1.4** | P0 渲染实值 |
| 卡片圆角 | 旧记录 6px | 圆角/卡片画板均 8px | **8px** | P0 + 用户确认 |
| 品牌色 | 画板 #006D9B | 库内残留 rgba(0,109,155,.16) | **#00B1B4** | USER_OVERRIDE |
| 胶囊 Tab 选中态 | 旧文档"浅品牌底" | 单层=实心；二级=浅底 | **分开处理** | P0，见 C-21 |
