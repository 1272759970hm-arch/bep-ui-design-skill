# RAG 页面判断案例

> 本文件沉淀常见业务页面的判断过程，供检索参考。它不替代正式组件规范。

---

## 商品详情页

**关键词：** 商品详情、实物商品、自营商品、商品信息、操作记录、商品标题、下架、编辑、下发门店。

**页面类型：** 对象详情页。

**推荐结构：**
- 系统页头：按当前系统选择“完整页头”或“顶部栏 + 系统页签”模式。
- 业务对象区：使用页头标题型（`bepHeaderTitle`）。
- 对象摘要：由页头标题型内部组合对象标题摘要（`bepObjectTitle`）。
- 操作按钮：由页头标题型右侧操作区承载，按钮使用按钮（`bepButton`）。
- Tabs：如果“商品信息 / 操作记录”控制整个商品详情主内容，使用对象标题内置 Tabs（`bepHeaderTitle.tabs`）。
- 内容：商品信息下的基础信息、销售信息、媒体信息等亲近关系强时，可放同一个页面级 Card，用描述列表（`bepDescriptions`）分 sections。
- Tab 内容：必须按 `activeTab` 分支渲染。商品信息页签只显示商品静态资料、配置和明细；操作记录页签单独显示动态记录。
- 操作记录：必须使用时间轴（`bepTimeline`）标准组件，不得手写时间轴近似结构。

**禁止做法：**
- 不得把对象标题摘要单独画一块，再在下方用卡片内页签（`bepCardTabs`）承载“商品信息 / 操作记录”这类整页主内容切换。
- 不得为了放 Tabs 单独套一个空的页头标题型。
- 不得把操作记录、库存流水、价格变更历史等弱相关动态记录强行塞进商品信息同一个描述列表。
- 不得在 `activeTab:0` 的商品信息页签中渲染操作记录内容。
- 不得在页面脚本里自造 `TimelineItem`、`LogRow`、圆点连线或操作记录局部组件替代时间轴。

**拆卡片判断：**
- 同卡片：基础信息、分类品牌、编码、销售属性、媒体信息、上下架状态等围绕商品身份的静态资料。
- 独立卡片或独立 Tabs：库存流水、审核记录、操作日志、价格变更历史、门店差异配置。动态记录类进入对应 Tabs 后使用时间轴标准组件。

**正式规则位置：**
- 页头标题型和对象标题摘要：`components-layout.md`
- 对象标题内置 Tabs / 卡片内 Tabs 判定：`SKILL.md` 与 `components-layout.md`
- 描述分组亲近关系：`SKILL.md` 与 `page-templates.md`

## 详情页描述列表

**关键词：** 详情页、描述列表、基础信息、扩展信息、附件、图片、标签、链接。

**判断规则：**
- 描述列表仍是 `label + value` 单一结构。
- 标签、链接、附件、图片/视频都属于 value 类型，不改变描述列表结构。
- 已有固定 value 子组件时，页面脚本传结构化数据，不手写图标、标签或坐标。
- 多个描述分组先判断业务亲近关系，相近放同一个页面级 Card，弱相关拆独立 Card。

**正式规则位置：**
- 描述列表：`components-layout.md`
- 描述列表 value 类型：`SKILL.md` / `components-layout.md`

## 普通列表页

**关键词：** 列表、查询、新增、批量操作、分页、表格。

**推荐结构：**
- 完整页头。
- 页面级 Card。
- 筛选区。
- 操作区。
- 表格。
- 分页器。

**注意：**
- 表格必须按列建模，输出列宽审计。
- 操作列必须使用操作列（`bepActionCell`）和操作列宽度计算（`bepActionMetrics`）。
- 表格文字必须使用表格文字（`bepTableText` / `bepTruncText`）。

**正式规则位置：**
- 表格：`SKILL.md` / `advanced-table-rules.md`
- 筛选区：`filter-rules.md`
