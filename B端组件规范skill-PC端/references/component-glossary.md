# BeP 组件中文命名表

> 用于统一团队沟通口径。讨论规范、页面结构和组件选择时，优先使用中文组件名；首次出现或涉及代码实现时，使用“中文组件名（`英文函数名`）”。

---

## 使用规则

- 中文组件名是对外沟通名称，英文函数名是脚本实现入口。
- 与用户、产品、设计、同事讨论时，默认说中文组件名。
- 写代码、查校验器、定位文件实现时，使用英文函数名。
- 同一个组件不得在不同文档里使用多个中文名；需要改名时同步更新本表、`SKILL.md` 和相关组件文档。
- 组件名称只解决“怎么叫”，不改变组件使用规则；具体样式、交互、内容约束以对应组件文档和 `scripts/bep-components.js` 为准。

## 页面结构与导航

| 中文组件名 | 英文函数名 | 层级 | 用途 | 易混淆项 |
|---|---|---|---|---|
| 完整页头 | `bepHeader` | 模块 | TopBar + 面包屑栏的组合页头 | 不等同于页头标题型 |
| 顶部栏 | `bepTopBar` | 模块 | 系统顶部操作区、业务系统切换、用户信息 | 不承载业务对象标题 |
| 面包屑栏 | `bepTitleBar` | 模块 | 当前旧 API 名；语义为 BreadcrumbBar | 不等同于系统页签 |
| 面包屑 | `bepBreadcrumb` | 复合组件 | 独立路径导航文本 | 不承载页面打开机制 |
| 系统页签 / 页面页签 | `bepTabs` | 模块 | TopBar + PageTabs 模式下的系统级页面页签 | 不用于业务状态切换 |
| 页头标题型 | `bepHeaderTitle` | 模块 | Header 下方的业务对象标题摘要区，可带操作按钮和对象标题内置 Tabs | 不替代完整页头 |
| 对象标题摘要 | `bepObjectTitle` | 复合组件 | 图片 + 主标题 + 状态 + 标签 + 副标题 | 不包含操作按钮和 Tabs |
| 对象标题内置 Tabs | `bepHeaderTitle.tabs` | 内部能力 | 对象详情页中控制整页主内容的标题型 Tabs | 不等同于卡片内页签 |
| 卡片内页签 | `bepCardTabs` | 复合组件 | 内容卡片内部的局部内容切换 | 不用于系统页面页签 |
