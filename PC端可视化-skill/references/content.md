# Content Guidelines

> v1.3.0离线执行：来源链接/节点仅供追溯，常规生成不调用Figma。使用本地模板和证据，执行方式以[离线组件合同](offline-components.md)优先；原规范的样式/口径仍有效，缺口不得伪装为完整还原。

面向移动看板、图表和指标明细。项目明文优先且保留业务版本；新增写法明确标为建议。展示文案与计算口径、接口字段分别处理。

## 01 / 标题、指标与术语

项目表达归纳 + 补充建议

### 名称表达任务

标题用“对象+指标/任务”：区域累计收入、实收金额趋势、收费率排名。副标题补组织、时间、累计/单值、单位，避免只写“分析”或“数据”。

### 保留业务区别

收入、实收、应收、收缴、追缴、预存不得互换；收费率、完成率、增长率分别保留名称和分母。年度/月度是查询粒度，累计/单值是数值口径，不混为同一组Tab。

### 缩写与标点

面向用户优先写“同比”“环比”，紧凑图例已有“同/环”时保持可解释。中文说明用中文标点；数值符号、小数点、负号、%、时间冒号保留常用形式。实现术语不进入用户文案。

### 推荐写法（示意）

实收金额趋势
按月 · 累计值 · 单位：万元

### 避免写法

数据分析 / 金额趋势
未说明时间、累计口径与单位

## 02 / 计数、量级与单位

项目明文4424:53017 + 目标金额分档；负数判档为补充建议

### 不加千位分隔符

正负数均不加千位逗号：123456789按量级可显示12345.68万，而非123,456,789。舍入只影响展示，原始计算值保留。

### 量级边界

目标金额表明确<1万、≥1万且<1亿、≥1亿，本板按该分档补齐等号。负数按绝对值选择量级并保留负号为补充建议；不擅自推广为所有坐标轴自动算法。

### 单位跟随数值

项目默认金额省略“元”，保留万/亿；目标与实际页面也有万元/亿元。业务已明确单位则沿用，独立读数缺少单位上下文时建议展示完整单位，不丢量纲。

### 同图统一单位

同一数值轴、同量纲比较系列统一量级；双轴数量与百分比各自标单位。自然单位人/户/个/笔不互换；复合单位如人/户保留完整。

### 金额精度示意

9876 → 9876.00元
12453500 → 1245.35万元
23560000000 → 235.60亿元

### 负值与边界示意

-12453500 → -1245.35万元（建议）
10000 → 1.00万元
100000000 → 1.00亿元（采用目标分档）

## 03 / 小数精度与图表刻度

项目数字与坐标轴明文；比率全局精度仍待统一

### 按单位类型保留

元、平方米等度量衡：进位前后2位；人、户等自然单位：未进位整数，进位后2位；人/户等复合单位：始终2位。不要把所有数字统一2位。

### 比率按指标定义

目标文案倾向百分比2位，但项目有79.8%等变体，不能覆盖成全局强制2位。%紧跟数字；占比、完成率与增长率虽同带%，计算关系各不相同。

### 刻度独立格式化

Y轴固定6档，原则最多1位小数；步长0.25等特殊可2位。出现1.5则1显示1.0；整数步长不加小数。不可把主金额2位精度直接套给全部刻度。

### 舍入边界待确认

临界进位、舍入到下一量级、负0、极小比率与总占比舍入误差须统一策略；不凭示例声称已有完整格式化函数。建议避免显示-0.00，保留原始计算精度。

### 单位精度示意

1243.80元 / 12户
2.20万户 / 2.50人/户

### 同轴刻度示意

有小数：0.0、0.5、1.0、1.5
整数步长：0、1、2、3
仅示意标签精度，非完整六档样例

## 04 / 百分比、百分点与同环比

完整比较期、状态、组件样式与冲突记录见[同环比规则](comparison-rules.md)。本节只保留数字文案的基本区分。

业务口径分开；以下算例为补充建议，非业务数据

### 百分点不是百分比增长

本期87.50%、上期85.00%，直接差额为+2.50个百分点；相对增长为(87.50−85.00)/85.00≈+2.94%。两者不能都标“+2.50%”。

### 金额差额写单位

涉及金额的同比/环比，项目历史说明有改为具体差额的版本。写“同比增加100.00万元”需确认确为金额差，不把金额差额加百分号。

### 显隐与比较期有冲突

框架写年度仅同比、月度两者、按日仅环比；比较期示例又有年环比、日同比，部分为当前未完月对历史整月。按具体指标版本确认，不静默改成同进度。

### 颜色不代替含义

涨绿跌红为项目框架做法；成本、流出上涨不自动代表经营改善。差额文字、符号和单位必须保留，风险灯号另按业务规则定义。

### 百分点差额

本期87.50% / 上期85.00%
较上期提高2.50个百分点

### 相对增长与金额差

较上期增长2.94%
同比增加100.00万元
以上为两类不同计算口径

## 05 / 日期、时间与数据新鲜度

目标日期规则 + 项目日历及首页规则

### 面向用户的日期

完整日期YYYY年M月D日，月份YYYY年M月，短日期M月D日；月日个位不补零。修正原“YYYY年M月/D/日”混写。时刻可用16:00，图轴按小时/日/月简写，不强塞完整年月日。

### 查询粒度对应范围

本日0:00至当前小时，历史日0:00至24:00；本月1日至当前日，历史月按真实天数；本年1月至当前月，历史年1至12月。具体指标是否支持按日仍按版本。

### 更新时间说真实范围

“数据截至”表示数据覆盖时点，“最近更新”表示更新时间；收入T+1等延迟口径需保留。首页取最新有数据月份的年累计时，不伪装为当前月实时数据。

### 历史锁数说明

回看历史节点时说明为锁数快照，不能把各历史快照相加与当前累计比较。接口日期、导出字段及历史YYYYMM表格值不因中文文案规范擅自改数据格式。

### 日期显示

2026年8月30日 / 2026年8月
8月30日 / 16:00

### 范围与时效（示意）

2026年截至8月累计 · 收入T+1
数据截至2026年8月30日
最近更新：2026年8月31日

## 06 / 图表、图例与明细文案

项目表达归纳 + 补充建议

### 标题与图例分工

标题说明任务，图例说明系列；同一系列名称、色标、线型与明细一致。图例需要区分本期/同期、正值/负值、合计；虚线不能一律解释为同期。

### 明细保留精确口径

选中时点明细显示时间、系列、值、单位及比较值；数量/金额/比率不共用占位单位。“当月净额”与“累计值”有历史冲突，未确认前不互称。

### 环形与转化

构成图分类名、占比、金额及分母一致；独立多环不相加为100%。阶段转化率写明相邻阶段或全链路分母，不能把样例中5.8%当已验证公式。

### 解释与取数口径

指标释义说明含义、分子分母、统计范围、时间和延迟。入口可用“指标释义”“取数口径”“查看明细”；Demo、复用H5等实现备注放设计注释。

### 图例与明细（示意）

本期（正值） / 同期（正值）
时间：2026年7月
累计值：100.00万元 / 同期值：80.00万元

### 口径说明模板（建议）

指标名称｜分子 / 分母
组织范围｜统计时间｜累计或单值
单位｜数据延迟｜特殊排除项

## 07 / 超长文案与缩写

组织名省略有项目依据，其余为本次补充建议

### 组织名

首页组织快捷切换的名称宽度固定、超出省略是项目已有规则；范围选择或详情中应能识别完整组织名。补充建议优先尾部省略，重名时保留能区分组织的关键段。

### 标题、图例与标签

标题/解释优先换行；图例可换行或独立明细，不通过无说明的自造缩写减字。图轴长类别可多行、减少显示密度或转横条，具体行数与触摸查看完整文本待确认。

### 数值不能随意截断

金额优先量级进位，必要时调整布局；负号、小数点、百分号、单位与数字作为一个语义单元保留。不显示8726…来替代完整金额，不将万元截成万…引起歧义。

### 术语缩写有边界

“同比/环比”在紧凑场景可依已有习惯显示“同/环”；“归母税前利润（剔除…）”不能删掉会改变统计口径的括注，允许标题简写但旁边需可查完整口径。

### 组织名称处理（示意）

完整：青岛主城大项目（物业）
紧凑：青岛主城大项目…
省略策略是建议，不代表已实现展开行为

### 数值保持完整

推荐：8726.40万元
避免：8726… / 8726.40万…
需要时进位或重新排版

## 08 / 0、缺失与异常状态文案

0与暂无数据需区分；以下文案及操作名称为补充建议

### 真实0

显示0、0.00或0.00%，精度按指标；不要改成“暂无数据”。有分子0且分母有效时才可显示真实0%。

### 暂无数据与建设中

暂无数据：当前筛选范围内暂无数据；建设中：数据建设中，暂未提供该指标。两者分开，不用同一空态掩盖开发状态。

### 加载、失败与无权限

加载中：正在加载数据；失败：数据加载失败，请重试；无权限：暂无该范围的查看权限。操作“重试”“调整筛选”仅在真实存在可用行为时出现。

### 无法计算与缺失

分母为0：—，说明“分母为0，暂无法计算”；缺失：—，说明缺失原因。破折号不替代真实0，缺失值不亮绿灯。具体错误码、重试及无权限流程待产品定义。

### 负值与超额

保留-6.20%、107.05%等真实值，可解释负值或超目标；不截断成0/100，也不自动称“异常”或“达标”，业务判断另依阈值。

### 区分真实0与无数

实收金额：0.00万元
暂无数据：当前筛选范围内暂无数据
建设中：数据建设中，暂未提供该指标

### 无法计算（建议）

完成率：—
分母为0，暂无法计算
与0.00%有明确区别
