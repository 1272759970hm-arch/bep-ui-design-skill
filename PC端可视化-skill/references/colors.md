## neutral

### 主值 / 强调 / #22262F

主要数值与重要正文；图表、字体板保持一致。

### 正文 / 次强调 / #444F60

正文、指标名、一般说明。

### 弱信息 / #9199A2

辅助信息、未选Tab等现有角色；重要读数不依赖弱灰小字。

### 提示 / 禁用候选 / #CCCFD6

原目标提示/禁用；问数还用作参考线，不把所有同色都解释为禁用。

主卡、明细及弹层白底；需与页面背景区分。

### 页面背景 / #F3F8F8

实际项目与目标页背景角色。

### 弱填充 / #F2F3F5

目标中性填充；不冒充缺失值或0值。

### 通用分割线 / #EEEEEE

目标通用分割线；与图表网格分开记录。

### 详情网格 / #E5E6EB

### 问数网格变体 / #E5E5E5

## semantic

### 风险灯 / 绿 / #0FD486

具体业务达到该版绿灯条件；不是所有指标上涨。

### 风险灯 / 黄 / #FFAC46

业务处于该版黄灯区间；不等于全部“未完成”。

### 风险灯 / 红 / #FF375F

业务达到红灯阈值；同色还可用于负值，但语义分开。

### 正值柱 / 本期 / #33C1C1

现金流正值的方向编码，结合零线及符号。

### 负值柱 / 本期 / #FF375F

现金流负值方向编码，不能仅靠颜色判断好坏。

### 历史浅粉候选 / #FEB7B7

目标曾用于缺口/负值；不是当前项目统一负值主色，也不当全部错误文字色。

Source: 4424:85610、4424:86517

## 品牌意图与数据编码分开

目标已有“洞察、实时、信任”的品牌定位，可指导整体视觉。品牌辅助候选、分类系列色、正负色、灯号色和控件选中色分别定义，不能用品牌心理描述替代数据规则。

## 系列映射保持稳定（建议）

同一业务系列跨日期、筛选和相关页面保持颜色对应；分类排序变化时不随序号重新换色。图例、选点、图形和明细一致；系列新增时再核对色序及辨识度。

## 透明度不是新色号

同一底色在白底、页面底或叠加填充上的视觉不同；opacity需连同背景及作用层记录。节点opacity、paint.opacity、渐变停靠点不能互相替代，嵌套透明度需实际核对。

## 线型与深浅另有语义

项目某些同期用虚线，但widget“合计”也用虚线。现金流同期用半透明柱。不要只写“虚线=同期、浅色=禁用”，须写清对应业务。

## 文字与可辨识性（建议）

浅青、弱灰和风险色在白底的小字可能偏弱。关键数值保留深文字色；图例同时用名称、形状/线型及数值，不能仅靠红绿或近色辨认。真实尺寸、灰度及实际背景需检查，本次不宣称完成无障碍验收。

## 色差、主题与发布边界

#66A6FF/#66A7FF、#3DC7F8/#3FC7F8、#949CF8/#959CF9等按来源记录；本次不强制统一、不修改全局变量。暗色、高对比主题及色盲替代配色尚未定义。
