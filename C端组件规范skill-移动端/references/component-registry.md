## 2. 标签系统（6 大类，配色限定）

| 大类 | 包含内容 | 常见标签 | 配色规则（强制） |
|---|---|---|---|
| **服务标签** | 配送方式 | 快递邮、极速达、自提、到店 | **限定 2 色**：代发用绿、门店类用蓝 |
| **店铺标签** | 店铺身份、认证、经营 | 自营、官方、入驻 | **限定 2 色**：自营/官方 `#FF6815`；入驻 `#D38D61` |
| **营销标签** | 促销方式、活动身份、价格权益 | 满减、直降、秒杀、会员价、新人专享 | **限定 2 色**：促销类用红、会员/专项类用金 |
| **商品标签** | 属性、身份、适用场景、口碑热度 | 新品、爆款、当季、进口、低糖 | **限定 3 组渐变**，同时存在时必须用不同颜色 |

**到手价规则（2026-11-06 补录，Figma 价格系统规范表实读）**
- 常规商品卡 / 加购的价格结构固定为「**到手价 + 现价 + 原价**」三段，到手价前缀与现价**同色同变体**
- **常规款**（商品卡、加购等营销场景）：到手价 + 现价 = `#FF6815`，原价 = `#969799` 删除线
- **特殊款（仅订单页面）**：到手价 + 现价 = `#262626`（N8），原价仍 `#969799`——订单页是严肃结算语境，整组去橙
- 到手价前缀 ≤3 字、14pt Medium，与现价**基线对齐**（不是顶对齐）

**硬规则**
- 现价永远 `#FF6815`；原价永远 `#969799` + **删除线**——**唯一例外**是订单页面的到手价组（见上）
- 「已优惠/共优惠」小字用红（营销语义），实付金额在订单页用 `#262626` 而非橙色
- 金额数字推荐 `MiSans Demibold`（终稿通栏按钮用 MiSans，PingFang SC 无对应字重时用 Semibold 兜底）

### 4.0 按钮使用场景映射（硬约束，2026-11-06 定稿）

> 表里没有的场景 → 回 Figma 交付稿找到对应画板实测后再写，不许凭感觉拼一个。
> 反例（已作废）：商品流卡片 footer 自创「加购」描边文字 pill——设计稿实为**纯图标 + 圆钮**（§4.9）。

### 4.8 快捷筛选 Tabs（2026-11-05 实读定稿：1:6155 白底版 / 1:6868 灰底版）

**按页面背景色选变体，两套样式不可混用**：

|---|---|---|

⚠️ 旧「白底 + `#C8C9CC` 描边」的筛选 chip 写法作废（那是规格选择 chip §4.3，两者不要混用）。
helper：`mkFilterTab(text, selected, pageBg, parent)`，`pageBg` 传 `'white'` 或 `'gray'`。

**变体判定规则（硬约束）**

| 判定 | 用哪套 |
|---|---|
| chip 所在容器的背景是白/接近白（白卡、白 sheet、白吸顶条） | 白底页面变体（灰 chip + 橙 10% 选中） |
| chip 所在容器的背景是 `C.bg #F2F3F5` 等灰底 | 灰底页面变体（白 chip + 橙 0.5px 描边选中） |

- 判定看 **chip 所在的局部容器底色**，不是整页背景——灰底页里放进白卡的筛选条，按白底算
- 两套变体**不可混用**：白底上放白 chip 会失去边界，灰底上放灰 chip 会糊成一片
- 典型归属：分类页 / 商品列表页顶部（白 sheet 内）→ 白底变体；商品列表（灰底直接铺开）、订单列表筛选条 → 灰底变体

## 6. 图标体系（2026-11-09 定稿：全量统一 Solar 圆润风）

> 起因：产品侧使用 icon control 时反馈图标「尖锐不圆润、风格不统一」——旧规范功能图标走 `lucide:*`（直线尖角），与组件库（Solar 圆角风）不匹配。**作废，全量切 Solar。**

**来源优先级（硬约束）**
1. **组件库 icon 组件实例**——生成 Figma 脚本时优先实例化（icon control 里的组件），保证和交付稿完全同源
2. **Iconify `solar:*`**——组件库不可用时兜底，风格与组件库一致（圆角端点、圆润转角）
3. **禁用 `lucide:*`**——直线尖角风，混用即违规

**Tab 图标**：Solar 线性/面性成对（`solar:xxx-outline` ↔ `solar:xxx-bold`），选中态用品牌色。

**金刚区分类图标（23 个，3D 质感）**：
