# 05 · Visual Strategy (C 端视觉策略)

> Skill 强制流程 Step 5。
>
> **这一步的目标：消灭"后台系统感 / 模板感 / 组件库 Demo 感"，建立 C 端产品的品质感、品牌感、商业转化能力**。

---

## Visual Rhythm 五要素（主动创造对比）

**C 端页面必须在这 5 个维度上主动建立对比**。全部无对比 = 模板。

| 维度 | 有节奏 | 无节奏（后台感）|
|---|---|---|
| **大 vs 小** | 主图 320px + 缩略图 80px | 全部 100px 卡片 |
| **强 vs 弱** | 价格 28px 红 + 描述 12px 灰 | 全部 14px t2 |
| **密 vs 疏** | 商品密集网格 + 留白引导视线 | 均匀网格铺满 |
| **图 vs 文** | 顶屏 70% 图 + 30% 文 | 全部白卡 + 文字 |
| **色 vs 白** | 品牌主色块 + 大面积白 | 全通白底 |

**规则**：一个页面必须**至少 3 个维度**有明显对比。

## 内容密度控制表

| 页面类型 | 整体密度 | 主图占比 | 文字占比 | 留白占比 |
|---|---|---|---|---|
| 首页 | 高 | 40-60% | 20% | 20% |
| 活动/营销页 | 高 | 50-70% | 20% | 10% |
| 商品列表 | 中高 | 50% | 30% | 20% |
| 商品详情 | 中 | 40% | 40% | 20% |
| 购物车 | 中 | 20% | 50% | 30% |
| 订单/表单 | 低 | 5% | 40% | 55% |
| 个人中心 | 中低 | 15% | 30% | 55% |
| 反馈页 | 极低 | 20% (大图标) | 20% | 60% |

**违规**：不管什么页面都用低密度 = 表单页做法 = 首页失败。

---

## 视觉焦点（每页仅 1 个）

**规则**：每个页面必须能**一秒指出"焦点在哪"**。

| 页面 | 焦点 | 表现手法 |
|---|---|---|
| 详情页 | 商品主图 | 375×375 顶屏、无干扰 |
| 首页 | Banner 主推位 | Hero 占屏 40%+ |
| 支付成功 | 大绿勾图标 | 56-80px 居中 |
| 优惠券页 | 金额数字 | 60-80px 主色 |
| 会员页 | 等级标识 | 装饰背景 + 金色徽章 |
| 订单详情 | 当前状态 | 大字 + 状态色 |

**焦点必须同时满足**：
- 视觉中心（顶屏 40% 内）
- 最强色彩对比
- 尺寸最大

## 色彩策略

### 品牌色使用密度

| 场景 | 品牌色应用 |
|---|---|
| 主 CTA 按钮 | 全填充 |
| 选中态 tag | 全填充 |
| 强调标签 | 全填充 |
| 链接文字 | 只用色 |
| 装饰细节 | 少量点缀 |
| 大面积背景 | ❌ 除非活动页 |

**规则**：品牌色的曝光 = "点、线、面" 递减 —— 大量点、适量线、极少面。

### 功能色应用（2026-11-05 配色方案 N 系列定稿，1177:24677）

| 色 | 场景 |
|---|---|
| primary `#FF6815` | 主操作、选中项、**常规现价**（价格默认用品牌橙，不是红） |
| danger `#ED392B` | **促销标签、倒计时、未读角标**；错误、紧急、删除操作 |
| success `#11C770` | **快递代发**、成功反馈、通过状态 |
| info `#12BFEA` | **门店履约**（极速达/自提/到店）、链接、辅助提示 |
| 入驻棕 `#D38D61` | 入驻商家身份标签 |
| 深棕 `#6A4B1F` + 浅金底 `#FFF1DF` | 会员权益标签 |
| warning `#FF8A1D` | 待处理、次要提醒 |

> ❌ 已作废：`danger 红 = 价格`。**订单页商品价用 N8 `#262626`**，常规现价用品牌橙。
> 浅底/描边一律取标准色 **8% / 24%** 透明度。

### 灰阶使用（N 系列）

| 灰阶 | 用途 | 用量 |
|---|---|---|
| N8 `#262626` (t1) | 主文字1：主标题、正文 | 多 |
| N7 `#646566` (t2) | 主文字2：主要文本 | 多 |
| N6 `#969799` (t3) | 辅助说明、原价、未选中导航 | 中 |
| N5 `#C8C9CC` (placeholder/disabled) | 提示文字、disable | 少 |
| N3 `#EBEDF0` (divColor) | 边框、分割线 | 微量 |
| N1 `#F7F8FA` (gray2) | 内容背景、三级按钮底、chip 未选底 | 少 |
| N2 `#F2F3F5` (bg) | 页面背景 | 大面积 |

## 反 "组件库 Demo 感" 清单（强制自查）

出现以下任一 = **违规，必须重构视觉策略**：

- [ ] 全部区域都是"白卡 + 圆角 12 + 灰字"
- [ ] 通篇字号只有 14 和 12 两档
- [ ] 主 CTA 和普通按钮视觉重量相同
- [ ] 图片全是占位符或均等大小
- [ ] 没有任何色块背景
- [ ] 没有任何 Hero 区 / 主视觉区
- [ ] 页面顶部第一屏没有商业转化元素（详情/首页/活动页场景）
- [ ] 分割线数量 > 卡片数量（过度分割）
- [ ] 所有卡片一样大 / 一样风格
- [ ] 没有任何"打破均衡"的元素（一个色块、一张大图、一个大数字）

## 品牌感与运营感（C 端专属）

### 品牌感 = 品牌 DNA 在页面上的显性表达

| 要素 | 检查项 |
|---|---|
| 品牌主色曝光 | 关键位置（CTA / 选中态 / 强调）用品牌色 |
| 一致的圆角语言 | 全站用同一圆角（如 12 / 8 / 4）|
| 一致的图标风格 | 同一图标库、同复杂度 |
| 品牌字体基调 | 中文 PingFang SC / 数字用 Medium/Semibold 强化 |

### 运营感 = 让用户感受到"这里有活动、有商品、有诚意"

| 手法 | 例子 |
|---|---|
| 大数字 | "已售 1024" / 优惠 "¥100" 大字 |
| 倒计时 | 活动结束倒计时 |
| 促销标签 | "限时立减" / "满 199 包邮" 醒目 tag |
| 徽章标记 | "官方旗舰" / "18+ 已验证" 权威感 |
| 状态高亮 | "在售" / "已抢完" 视觉分明 |

**规则**：C 端页面（非表单/设置）必须有**至少 2 个运营感元素**。

## 商业转化设计

### 主 CTA 视觉法则

- **色彩**：品牌色或危险色（红），高对比
- **尺寸**：宽度充满可用区域，高度 ≥ 44px
- **位置**：sticky bottom（详情/购物车/结算）或视觉终点
- **文案**：动词开头（"立即购买"、"提交"、"领取"），禁止"确定/OK"

### 转化辅助元素

| 元素 | 说明 |
|---|---|
| **紧迫感** | 倒计时、"仅剩 3 件"、"今日截止" |
| **社会证明** | "已售 X 份"、"好评率 98%"、"1024 人正在购买" |
| **优惠可视化** | 原价划线、立减金额、券后价 |
| **风险消除** | "7 天无理由"、"正品保障"、"运费险" |

## 页面情绪匹配（Step 1 Why → 视觉基调）

| 用户情绪 | 视觉基调 | 举例 |
|---|---|---|
| 探索 / 好奇 | 丰富、活力、多入口 | 首页 |
| 决策 / 犹豫 | 信任感、清晰对比 | 详情页 |
| 完成 / 放松 | 大留白、单一信息、绿色 | 支付成功 |
| 焦虑 / 紧急 | 清晰状态、明确指引 | 订单异常、报事页 |
| 尊贵 / 特权 | 深色 + 金色 + 装饰 | 会员页 |
| 兴奋 / 促销 | 强色、大数字、动感 | 活动页 |

**违规**：所有页面用同一视觉基调（比如全部白底灰字冷淡）。
