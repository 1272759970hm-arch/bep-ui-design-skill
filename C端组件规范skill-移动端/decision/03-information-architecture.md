# 03 · Information Architecture (信息架构)

> Skill 强制流程 Step 3。
>
> **视觉层级必须与信息优先级一致**。信息优先级不明 = 页面视觉必然混乱。

---

## P0-P4 优先级定义

| 级别 | 含义 | 判断标准 | 视觉权重 |
|---|---|---|---|
| **P0** 核心任务信息 | 用户来此的**唯一**原因；缺失 = 页面失败 | "如果没有这条，用户白来" | 最大字号（20-32px）+ 最强色（主色/危险色）+ 顶部或视觉中心 |
| **P1** 核心业务信息 | 支持 P0 决策的关键内容 | "缺了它 P0 无法完成" | 16-18px Medium + 主文字色 + 紧邻 P0 |
| **P2** 辅助决策信息 | 帮助判断但可折叠 | "有更好，无也能做决定" | 14px Regular + 次文字色 + 卡片内可折叠 |
| **P3** 补充信息 | 有更好，无也可 | "锦上添花" | 12px Regular + 弱文字色 + 次要位置 |
| **P4** 弱化信息 | 法律 / 隐私 / 条款 / 次要链接 | "合规必须但用户不关心" | 11px Regular + t4 灰 + 页脚 |

---

## 优先级 → 视觉权重（强制映射）

**规则一：字号阶梯**

| P 级 | 字号范围 | 字重 |
|---|---|---|
| P0 | 20-32px | Medium/Semibold |
| P1 | 16-18px | Medium |
| P2 | 14px | Regular/Medium |
| P3 | 12px | Regular |
| P4 | 11px | Regular |

**规则二：颜色阶梯**

| P 级 | 颜色 |
|---|---|
| P0 | 品牌色 / 功能色 / t1（视场景）|
| P1 | t1 (#333) |
| P2 | t2 (#666) |
| P3 | t3 (#999) |
| P4 | t4 (#BBB) |

**规则三：位置阶梯**

| P 级 | 位置策略 |
|---|---|
| P0 | 视觉中心（顶屏 40% 内）+ 独立空间（不与其他信息竞争）|
| P1 | 紧邻 P0，形成"P0 + P1 视觉组"|
| P2 | 卡片内 / 可折叠 |
| P3 | 页面中下部 |
| P4 | 页面底部 / 折叠区 |

**规则四：数量限制**

| P 级 | 每页允许数量 |
|---|---|
| P0 | **必须 = 1**（多个 P0 = 目标不清）|
| P1 | ≤ 3 |
| P2 | ≤ 6 |
| P3 | 不限（但需组织好）|
| P4 | 不限 |

## 示例：商品详情页 IA

```
## Information Architecture

P0 (核心任务)：
- 商品主图        (视觉焦点)
- 价格            (决策关键)
- 立即购买 CTA    (完成任务)

P1 (核心业务)：
- 商品名 + 卖点
- 规格选择
- 优惠信息 (立减/满减)

P2 (辅助决策)：
- 用户评价摘要 (好评率 + 数量)
- 配送信息
- 服务保障

P3 (补充)：
- 详情图文
- 相关推荐

P4 (弱化)：
- 商家资质
- 举报入口
```

**视觉映射**：
- 主图 375×375 顶屏（P0）
- 价格 ¥ + 28px 红字 Medium（P0）
- 立即购买 sticky 底部大按钮（P0）
- 商品名 16px Medium（P1）
- 评价用小 Card + 展开箭头（P2）
- 详情在 P0/P1 下方（P3）
- 举报隐藏在 ⋯ 菜单里（P4）

```
| P1 | [信息 2] | ... | ... |
| P1 | [信息 3] | ... | ... |
| P2 | [信息 4] | ... | ... |
| P3 | [信息 5] | ... | ... |
| P4 | [信息 6] | ... | ... |
```

## 常见反模式

### 反模式 1：视觉民主（Visual Democracy）

**症状**：所有信息用相同字号 / 颜色 / 间距 / 卡片。

**举例**：详情页里 "价格"、"评价"、"配送"、"相关推荐" 全用 16px Medium 白卡。

**修法**：拉开至少 3 级视觉层次（字号差 ≥ 4px、颜色差 ≥ 2 级）。

---

### 反模式 2：CTA 淹没

**症状**：主行动按钮和辅助内容视觉重量相同。

**举例**："立即购买" 和 "分享给朋友" 都是灰底黑字 40h 按钮。

**修法**：主 CTA 必须至少高一个视觉级别（主色 + 更大尺寸 + sticky 位置）。

---

### 反模式 3：信息通胀

**症状**：页面塞了太多，每条都想抢注意力。

**举例**：首页顶部并列 5 个 Banner + 8 个宫格入口 + 3 个提示条。

**修法**：强制 P0 = 1，P1 ≤ 3。多余的下沉到 P2 或删除。

---

### 反模式 4：优先级倒挂

**症状**：页面顶部放 P3 内容（如广告 banner 挤压商品位）。

**举例**：详情页顶部放"下载 APP 有优惠" banner，商品图被推到第二屏。

**修法**：顶屏必须只出现 P0 + P1，P2 以下下沉。

---

### 反模式 5：折叠错位

**症状**：核心信息藏在折叠区，装饰信息占顶部。

**举例**：订单详情页"物流状态"要点开"物流详情"才能看到，"分享订单"放在顶部。

**修法**：P0 永不折叠，P4 才折叠。

---

## AI 检查清单（Step 3 完成后自查）

- [ ] P0 数量 = 1 ？
- [ ] P1 数量 ≤ 3 ？
- [ ] P0 和 P1 的视觉映射（字号/颜色/位置）是否符合规则？
- [ ] 是否存在同级别信息用完全相同视觉的情况（视觉民主）？
- [ ] P2-P4 的信息是否可以合并 / 删除？
- [ ] 顶屏是否只有 P0 + P1？

任何一项不通过 → 重新做 IA。

---

## 与后续步骤的衔接

- P0 → 决定 Step 5 视觉焦点位置
- P0 + P1 → 决定 Step 4 user flow 的"See"和"Understand"内容
- P4 → 决定哪些内容默认折叠 / 页脚放
