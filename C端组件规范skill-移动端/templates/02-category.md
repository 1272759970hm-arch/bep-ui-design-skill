# 02 分类页

**画板**：分类页（375×812）、01 / 02 / 03（三版选品状态）
**可运行代码**：无（结构简单，直接用 preamble 拼）

## 区块顺序

| # | 区块 | 参考 y / 高 | 内容 | 组件 |
|---|---|---|---|---|
| 1 | 顶部搜索栏 | 0 / ~96 | 状态栏 44 + 搜索框（「搜商品」，白底胶囊 32h） | 自定义 |
| 2 | 快捷筛选 Tabs | 搜索栏下 / 28 | 「全部 / 西梅 / 榴莲 / 桃子 / 冬枣」横滑，右端渐隐 + 下拉箭头 | `mkFilterTab(…, 'white')` — **白底变体** |
| 3 | 左侧一级分类 | 96 / 716 | 竖排，「全部 / 柑橘类 / 核果类 / 浆果类 / 瓜果类 / 蔬果类」 | 92 宽竖列 |
| 4 | 右侧二级分类 | 96 / 716 | 两/三列宫格：分类图标 + 名称 + 商品数 | 网格 tile |
| 5 | 底部标签栏 | 页底 | 375×84 | `底部标签栏` |

左侧选中态：白底 + 左侧 3px 主色竖条 + 14pt 主色 Medium；未选：`C.bg` 底 + 14pt `C.t2`。

## 变体差异

| 版本 | 说明 |
|---|---|
| 分类页（主版） | 左栏「全部」选中，右侧展示一级下的全部二级 |
| 01 / 02 / 03 | 分别对应不同一级分类选中态（如柑橘类 / 浆果类），**只换左栏高亮 + 右侧内容**，骨架完全一致 |

## 易错点

- 左栏与右栏**必须**各自独立滚动，右栏顶部不漏白（右栏底 `C.white`）
- 左栏宽固定 92，右栏宽 283；右栏内物品距 12
- 二级分类 tile 用 3 列，图标 44 + 名称 12pt，tile 高 ≈ 96
- 本页**不要**加 PageHeader，顶部就是搜索栏
- 快捷筛选 Tabs 落在**白底**上 → 必须用**白底页面变体**（灰 chip + 橙 10% 选中），别用灰底变体
