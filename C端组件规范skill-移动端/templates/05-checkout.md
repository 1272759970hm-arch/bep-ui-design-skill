**4 个版本的差异**（1144 / 1211 / 1254 是长版，多出的高度来自商品行数）：

| 版本 | 差异 |
|---|---|
| 375×902 | 基础版：2 个商品行，无备注/发票 |
| 375×1144 | 加「费用明细」展开 + 备注 |
| 375×1211 | 加发票信息 + 优惠券选择 |
| 375×1254 | 商品行最多（4 行），含「下单成功」浮层态 |

**易错点**
- 实付款是**橙色**（确认页），但订单详情的「实付金额」要用 `#262626`（见 registry §3）
- 提交订单按钮与实付款同一行，按钮宽 126，不铺满
- 地址块下方那条彩色斜纹是品牌装饰，用两张旋转 45° 的矩形 + 主色渐变，别用图

- 顶部大留白 60 起，不要把结果区怼到状态栏下面
