# 06 极速达（门店即时零售）

**画板**：极速达（375×1640）、极速达大图（375×1650）、1037:20281
**可运行代码**：无（结构与首页高度相似，复用 `tpl-home.js` 改头图区）

> Hero 型 → 透明状态栏。与首页的核心差别：**门店 + 时效 + 倒计时**三件套。

## 区块顺序

| # | 区块 | 参考 y / 高 | 内容 | 组件 |
|---|---|---|---|---|
| 1 | 门店头图 | 0 / ~340 | 门店实拍 + 渐变；顶部定位「华南碧桂园」 | `mkImage` + 遮罩 |
| 2 | 门店信息条 | ~60 | 门店名 + 「距离门店 1.2km」+ 「极速达」蓝标（服务标签=门店类用蓝） | 标签 + 12pt |
| 3 | 搜索 | ~100 | 「搜商品」白底胶囊 32h | 自定义 |
| 4 | 时效条 | ~140 | 「06:27:38 前下单，1 小时内送达」倒计时（橙字 + 等宽数字） | 文本组 |
| 5 | 分类横滑 | ~180 | 极速达 / 推荐 / 生鲜 / 母婴 / 银发健康 … | chip 横滑 |
| 6 | 商品双列流 | ~220 / 长 | 商品卡 + 「抢」+ 预估佣金；带库存紧张提示 | 商品卡 |
| 7 | 底部标签栏 | 页底 | 375×84 | `底部标签栏` |

## 变体差异

| 变体 | 差异 |
|---|---|
| **极速达** | 标准版，门店头图 + 双列流 |
| **极速达大图** | 头图换成整屏大图（≈600 高），商品流推到下方；首屏只露出大图与倒计时 |
| **1037:20281** | 同骨架，商品流换品（另一家门店） |

## 易错点

- 倒计时数字用等宽（`MiSans Demibold` 或 `PingFang SC Semibold` + `tracking 0.5`），否则秒数跳动时会抖
- 「极速达」标签是**服务标签**，门店类必须用蓝，不要用品牌橙
- 库存紧张文案 11pt `C.danger`，紧贴价格下方
- 距离文案「1.2km」12pt `C.t3`，不要与门店名同字号
