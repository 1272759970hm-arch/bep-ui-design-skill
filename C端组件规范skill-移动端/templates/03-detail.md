# 03 商品详情

**画板**：详情页一屏（375×812）、详情页长图（375×3433）、详情页—节日（375×983）、详情页—阶梯价（375×812）
**可运行代码**：`tpl-detail.js`

## 区块顺序

| # | 区块 | 参考 y / 高 | 内容 | 组件 |
|---|---|---|---|---|
| 1 | 透明导航 | 0 / ~90 | 返回 / 分享 / 购物车，浮在主图上 | 图标按钮 32×32 |
| 2 | 主图轮播 | 0 / 375 | 方图 + 指示点；右下角「1/5」 | `mkImage` |
| 3 | 价格区 | 375 / ~110 | 特大价 `¥42`（品牌橙）+ 划线价 + **营销标签行在价格行下方**（4px 间隔）+ 「预估佣金」双段胶囊 | `mkTag` + 价格文本 |
| 4 | 标题区 | ~485 / ~70 | 商品名（16pt Medium，2 行）+ 卖点；**商品标签/服务标签挂品名首行前**（各 4px） | `mkTagNameRow` |
| 5 | 规格选择 | ~555 / ~56 | chip 行：「单瓶装 / 礼盒装」（选中描边橙） | `mkTagGroup` |
| 6 | 服务/配送 | ~611 / ~56 | 快递邮 / 极速达 · 送货上门 · 免运费 | `mkCellRow` 精简版 |
| 7 | 分享佣金条 | — | 「分享商品｜成交后得佣金」（浅橙底通栏） | `C.ext_cream` 条 |
| 8 | 详情图文 | 长图区 | 长图流，宽 375，逐张承接 | `mkImage` 序列 |
| 9 | 底栏 | 722 / 90 | 客服 / 收藏 / 购物车 + **双按钮组** | `mkBottomActionBar` |

## 关键规格

- 价格：**特大步阶** → 文字 14 / 符号 16 / 原价 16 / 现价 **28**
- 底栏双按钮：`type:'outline'`（加入购物车，106×40）+ `type:'primary'`（立即购买，106×40），gap 8
- 底栏高度 90 = 12 + 40 + 12 + 34 安全区（不含安全区时 56）

## 变体差异

| 变体 | 差异 |
|---|---|
| **详情页一屏** | 首屏骨架，用于验收上方折叠区 |
| **详情页长图** | 3433 高，主图之后接长图流；底栏 fixed 在 812 视图底部 |
| **详情页—节日** | 增加节日氛围头图 + 活动倒计时，价格区加「节日专享」金标（营销标签用金） |
| **详情页—阶梯价** | 价格区换成阶梯表：`1件 ¥29 / 2件 ¥55 / 3件 ¥78`，每档一行 + 分隔线；现价随选中档位高亮 |

## 易错点

- 主图区与价格区之间**不要**加分割线（图片下方直接接白底价区块）
- 规格 chip 是**描边款**，不是实心橙（见 registry §4.3）
- 阶梯价用「文字 14 + 现价 20」的**大步阶**，不要用特大的 28
- 长图流每张之间留 0 gap，但每张必须单独 `clipsContent`
