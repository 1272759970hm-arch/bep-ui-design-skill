## 1. 数字展示

| 项目原文范围 | 明确规定 |
|---|---|
| 计数 | 一万以内显示实际数字；超过一万、一亿以内进位万；超过一亿进位亿。示例100,000显示10万、100,000,000显示1亿 |
| 正负 | 计数规则同时适用正数和负数，不加千位分隔符 |
| 单位 | 放在数值之后，例如10元、10万元、10个；金额默认省略“元”，显示10、10万、10亿 |
| 度量衡单位 | 元、平方米等，无论是否进位都保留两位小数 |
| 自然单位 | 人、户等，未进位默认整数；进位后保留两位小数，例如2.20万户 |
| 复合单位 | 人/户等，无论是否进位都保留两位小数，例如2.50人/户 |

原稿的金额省略“元”说明与小数示例中保留“元”的写法并存；实现时应把“单位精度”和“是否展示元字”分别处理。万/亿恰好等于阈值的全部边界、负数取幅值进位的具体代码、百分比与百分点精度未由这里完整定义，不把示例补成未写出的统一函数。

## 2. Y轴进位与格式

| 项目写出的范围 | 坐标轴显示 |
|---|---|
| 最大值<1万 | 刻度不进位 |
| 最小值<1万<最大值 | 强制统一万级 |
| 最小值、最大值均位于1万与1亿之间 | 万级 |
| 最小值<1亿<最大值 | 强制统一亿级 |
| 最小值>1亿 | 亿级 |

同一Y轴按整组范围确定单位，不能把某个低刻度显示为元、另一个高刻度显示为万。轴规则是刻度专用格式，不机械套用业务主值的两位小数。

- 坐标轴整体高度固定，Y轴刻度数量固定6档。
- Y轴标签原则上最多1位小数；步长0.25等特殊情形允许2位，但原稿要求尽量避免。
- 同轴视觉对齐：若出现1.5，则整数1显示为1.0；步长为整数1、2、3时不加小数点。
- “六档”与金额进位已定义；最大值取整、nice-number步长、负数跨零、等于万/亿阈值、全0及缺失值仍没有完整算法。

## 3. X轴与适配

- 坐标轴宽度随屏幕宽度适配。
- X轴当前时间值固定在最右侧，刻度随时间进度变化。
- 当前时间端点与用户选中的时间点是不同概念，不因示例有16:00选中标记就把两者混同。

上述已经给出部分适配规则；具体断点、最小绘图区、标签避让、手势触发、离手保持和tooltip规则仍需另定。

## 4. 新发现的业务联动

项目页中明确写出：高级筛选的“账单主体类型”选中全部时，显示账单主体分析维度，趋势中显示账单主体类型；选中具体主体时，两处均不显示。不能只筛选数据而保留不适用的分析维度。

首页指标按最新有数据月份的年累计值展示；当月没有新数据，向前找有数据月份，并保留对应更新时间。此规则限定于该版首页，不自动覆盖详情页指定日期查询。

现金流、税前利润率和总成本等页面提示：历史节点展示锁数版本，不建议把历史节点数相加后与当前累计比较，原因包括往期应收调整。不能把不同历史快照当作可直接相加的时间序列增量。


## 当前整理稿补充的边界

主金额目标分档采用小于10000、达到10000且小于100000000、达到100000000。这补齐的是目标金额表等号，不是全局轴算法。轴负数、跨零、等号和全零仍待定义。高级筛选另有2026年2月25日去除“全部”等说明，不能把上面联动应用到所有指标；见business-and-interaction.md。
