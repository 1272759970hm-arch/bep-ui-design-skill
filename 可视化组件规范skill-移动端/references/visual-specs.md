| 利润完成率 | 32/40 Semibold；%为14/28 |
| 预存金额 | 22/32 Semibold；单位14/29或14/26，按变体 |
| 排名主名次 | DIN Bold24/24；“/77”为PingFang SC Semibold14/22 |
| 排名序号 | DIN Bold14/19、16/24，按场景 |
| 表格/明细 | PingFang SC14/22，标签Regular，重要值Semibold |

通用主值40/60来自候选阶梯，不覆盖28/32环心等专用样式。Noto Sans SC是整理时可用替代，不是品牌指定字体；Android Source Han Sans/系统字体方向尚无逐设备映射。数字与单位分别混排，检查基线，不能全局固定上移。8/10px历史widget小字不能作为移动正文推荐下限。
