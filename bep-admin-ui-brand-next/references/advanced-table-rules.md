# 高级表格规范

> Figma 真源：`BeP Admin Kit Sketch V1.1.0 / node 0:89`，页面标题为 `高级表格`，组件族为 `7.Business/2.Table  Advanced高级表格`。

高级表格不是普通 `bepTableHeader + bepTableRow` 的自由组合。只要出现表头筛选、列设置、拖拽排序、内联操作、树状层级、折叠详情、快速新增、多级表头等业务表格能力，必须优先按本规范生成。

---

## 通用规则

- 表格宽度根据屏幕尺寸与页面布局计算；当前 BeP 1440 屏幕标准宽度为 `TABLE_W = 1152`
- 标准表头高度：`48`
- 标准数据行高度：`48`
- 标准多级表头高度：`80`，上层分组 `40`，下层子列 `40`
- Checkbox 列宽：`48`
- 单元格左右内边距：`16`
- 表格必须按列建模：每列先定义 `label / width / align / render`，再把行数据填入列；不得按单行视觉结果反推布局
- 生成表格前必须输出/编写 `COL_WIDTH_AUDIT`：每列记录表头、最长内容、计算宽、最终宽，审计结果必须和实际 `cols` 一致
- 操作列继承左右内边距 `16 + 16`，是父级复合列，不拆成多个独立表格列；最多 3 个操作，超过 3 个时第 3 个变为更多；子级列按第1/2/3位操作分别统计实际数据最大宽度；父级列宽必须由 `bepActionMetrics(actionRows).width + 32` 得出；单行渲染使用 `bepActionCell(actions, {slotWidths: metrics.slotWidths})`；操作文本不得换行、不得省略
- 序号、编码/工号、日期、状态 Tag、电话不是固定预设宽度，而是按最大内容宽计算，默认不参与弹性
- 弹性列、文本截断、超宽表格冻结按 `page-layouts.md` 的通用列宽规则执行
- 高级表格列宽规则与基础表格一致；区别只是在基础表格上增加表头筛选、列设置、拖拽、树状层级、快速新增、多级表头等业务能力
- 表头背景：`rgba(0,0,0,0.04)`
- 表头文字：PingFang SC Medium，14px，line-height 22px，`rgba(0,0,0,0.85)`
- 数据文字：PingFang SC Regular，14px，line-height 22px，`rgba(0,0,0,0.65)`
- 单元格文字必须用 `bepTableText` / `bepTruncText` 固定在列宽内，不得用 `bepText` 直接渲染单元格
- 表格 checkbox 列使用 `bepTableCheckbox`，不得手写勾选框、对勾或用表单多选组近似表格单元格
- 可拖拽表格控制列使用 `bepTableDragHandle`，不得手写拖拽点阵或自定义 SVG
- 单元格内容无特殊要求不得换行
- 数值列使用 `bepTableText` / `bepTruncText` 时必须传 `alignH:'RIGHT'`，并按最宽完整数值反推列宽
- 表格总宽超过 `TABLE_W` 时，必须拆成内容视窗 + 冻结列
- 右侧冻结列使用 `BEP_SHADOW_FREEZE_RIGHT`，阴影落在当前列左侧
- 左侧冻结列使用 `BEP_SHADOW_FREEZE_LEFT`，阴影落在当前列右侧
- 高级树状表格行背景按层级区分：一级可展开行白底，二级/三级等子级行使用 `#F5F7FA`。这是 `内容-二级`、`内容-三级` 变体的标准底色，不是 hover/selected 状态。

以下各组件的 Figma 示例列宽只用于识别组件状态和参考真源结构，不作为页面生成时的固定列宽。实际页面生成必须先执行通用列宽规则。

## 何时使用高级表格

| 场景 | 使用规范 |
|---|---|
| 表头含排序、筛选、输入筛选、状态筛选 | 带表头功能表格 |
| 用户可选择显示/隐藏列 | 可设置表格 |
| 行可拖拽排序 | 可拖拽表格 |
| 行内有编辑、启禁用、更多等轻量操作 | 有内联操作的表格 |
| 权限点、菜单、组织等多层级数据 | 多层级展开表格 |
| 行展开后展示详情面板 | 折叠面板展开表格 |
| 表格首行提供新增入口 | 快速新增表格 |
| 新增时首行进入输入态 | 快速新增表格备份 |
| 表头有分组、跨列、跨行 | 多级表头表格 |

普通列表没有这些能力时，才使用基础表格。

## 带表头功能表格

**Figma 节点：** `0:212`，名称 `带表头功能表格`，尺寸 `1152×288`

**Figma 示例列宽：**

```javascript
[150, 217, 280, 123, 123, 123, 136]
```

**标准能力：**
- 表头可带图标，页面脚本必须使用 `bepAdvancedTableHeader(cols, tableW, opts)`；列级通过 `filter:true` 或 `iconKey` 指定图标。
- 筛选浮层挂在对应表头下方，不能脱离表格宽度体系。
- 示例浮层：
  - `出售率筛选`：x=150, y=48, w=162, h=104
  - `地址输入框`：x=367, y=48, w=240, h=104
  - `状态筛选`：x=770, y=48, w=140, h=164
- 带标识的数据单元格使用 `内容-带标示` 变体。

## 可设置表格

**Figma 节点：** `0:291`，名称 `可设置表格`，尺寸 `1152×290`

**Figma 示例列宽：**

```javascript
[48, 190, 160, 318, 120, 180, 136]
```

**标准能力：**
- 第一列固定为 checkbox 列，宽 `48`。
- checkbox 单元格使用 `bepTableCheckbox`。
- 列设置浮层在表格左上区域展开：x=0, y=48, w=334, h=242。
- 设置浮层属于表格的业务状态，不是页面级弹窗。
- 可设置表格仍遵守标准行高 48，不要压缩行高。

## 可拖拽表格

**Figma 节点：** `0:489`，名称 `可拖拽表格`，尺寸 `1152×288`

**Figma 示例列宽：**

```javascript
[48, 190, 160, 318, 120, 180, 136]
```

**标准能力：**
- 第一列固定为 checkbox/拖拽控制列，宽 `48`。
- 拖拽柄必须使用 `bepTableDragHandle()`，图标使用 BeP `Line/Drag`；不得手写点阵。
- 拖拽过程中允许显示横向插入指示线；示例指示线横跨全表宽，约 3px 高。
- 非拖拽状态下，数据行默认透明背景。

**Figma 示例列宽：**

```javascript
[238, 160, 318, 120, 180, 136]
```

**标准能力：**

- 操作列按通用操作列规则自适应，操作文字使用主色/危险色，不得换行或省略。

## 多层级展开表格

**Figma 节点：** `0:353`，名称 `多层级展开表格`，尺寸 `1152×433`

**Figma 示例列宽：**

```javascript
[48, 190, 160, 318, 120, 180, 136]
```

**标准能力：**
- 这是业务树状表格的标准来源，权限点、菜单、资源树优先使用此规范。
- 使用高级表格内容变体：`内容-可展开`、`内容-二级`、`内容-三级`。
- 层级同时通过展开图标、缩进和子级底色表达。
- 一级可展开行白底；二级、三级等子级行使用 `#F5F7FA`，包括 checkbox 列、普通内容列和操作列都应整行贯通同一底色。
- 展开/收起图标使用 BeP 图标规范中的 16×16 箭头，图标与文字间距 8px。
- 每级缩进以 16px 为基准；Figma 真源位置：一级 icon x=16、text x=40；二级 icon x=32、text x=56；三级叶子 text x=72。子级底色只是层级背景，不替代缩进和图标。
- 树状表格统一使用 `bepTreeRow`；不存在另一个“简单树表格”规范。有 checkbox 列时，名称列通常是第二列，调用 `bepTreeRow(..., {treeCol:1})`。
- 如果有多选，顶部可出现 `bepSelectionBar`，它属于表格内部状态栏。

**P-03 权限管理页面必须用此规范。**

## 折叠面板展开表格

**Figma 节点：** `0:411`，名称 `折叠面板展开表格`，尺寸 `1152×296`

**标准能力：**
- 行展开后出现全宽详情面板，详情面板位于该行下方。
- 示例详情面板：x=0, y=144, w=1152, h=104。
- 详情内容可展示 `姓名：张三`、`备注：...` 等键值信息。
- 展开详情面板使用 `bepTableExpandPanel(tableW, items, opts)`。
- 展开详情面板可以使用浅背景，但普通子行仍不得自动灰底。

## 折叠面板展开表格备份

**Figma 节点：** `0:446`，名称 `折叠面板展开表格备份`，尺寸 `1152×336`

**标准能力：**
- 用于行展开后内嵌更复杂内容，如嵌套明细或更完整的详情块。
- 表头仍使用高级表格 `表头` / `表头-带图标` 变体。
- 展开内容属于当前表格，不单独做 Card。

## 快速新增表格

**Figma 节点：** `0:573`，名称 `快速新增表格`，尺寸 `1152×288`

**标准能力：**
- 在表头下方提供一行新增入口。
- 新增入口使用 Dashed Button 样式，x=16, y=56, w=1120, h=32。
- 新增入口使用 `bepQuickAddRow(tableW, opts)`；内部复用 `bepButton(..., 'dashed')`。
- 该入口是表格首行状态，不是工具栏按钮；工具栏新增和表格内快速新增不要同时重复，除非业务明确需要两种入口。

## 快速新增表格备份

**Figma 节点：** `0:606`，名称 `快速新增表格备份`，尺寸 `1152×288`

**标准能力：**
- 用于点击快速新增后，首行变成输入态。
- 输入态单元格可显示 `请输入`、`-`、备注文本等占位内容。
- 首行输入态仍保持 48px 行高。

## 多级表头表格

**Figma 节点：** `0:95`，标签 `多级表头表格`，尺寸 `1152×369`

**结构：**
- 已选操作栏：y=0, h=48
- 表头区：y=49, h=80
- 数据行区：y=129 起，每行 48

**列结构：**

```javascript
[
  { label:'多选框', w:48, rowSpan:2 },
  { label:'单位', w:204, rowSpan:2 },
  { label:'干部数量', w:300, children:[
      { label:'子列一', w:100 },
      { label:'子列二', w:100 },
      { label:'子列三', w:100 }
  ]},
  { label:'MPB/M类人数分布', w:360, children:[
      { label:'子列一', w:112 },
      { label:'子列二', w:112 },
      { label:'子列三', w:136 }
  ]},
  { label:'日期', w:104, rowSpan:2 },
  { label:'操作', w:136, rowSpan:2 }
]
```

**标准能力：**
- 分组表头顶层高度 40，子表头高度 40。
- `rowSpan:2` 的普通列高度为 80。
- 数据行仍为 48，不因多级表头改变。
- 多级表头使用 `bepMultiLevelTableHeader(cols, tableW)`；不能用两个普通 `bepTableHeader` 粗略叠放，必须按分组列宽与 rowSpan/colSpan 对齐。

## 生成检查清单

生成含高级表格的页面前，逐项确认：

1. 是否命中高级表格场景；命中则不得退化为普通表格。
2. 表格宽度是否按屏幕和页面布局计算；1440 标准页是否为 1152。
3. 表头/数据行高度是否为 48，多级表头是否为 80。
4. Checkbox 列是否为 48；操作列是否按内容自适应，且操作文本不换行、不省略。
5. 树状层级是否符合一级白底、子级 `#F5F7FA`，并同时保留图标和缩进。
6. 是否误把表格状态浮层、展开面板、快速新增行做成独立 Card。
7. 页面级 Card 是否默认无阴影。
8. 是否有 `COL_WIDTH_AUDIT`，且长编号完整、数值右对齐、操作列不截断、冻结阴影方向正确。
