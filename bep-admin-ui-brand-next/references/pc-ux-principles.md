# PC 端体验基线

> 本文件规定 PC 后台产品的信息密度与效率底线。
> 数值全部来自 `design-tokens.md` / `filter-rules.md` / `form-rules.md` / `page-layouts.md` 实测；本文件只解决「该密还是该松」「操作距离多长」这类判断。

---

## 一、反 C 端化红线（不得违反）

后台系统的用户是**在职作业者**，不是浏览型消费者。以下做法禁止：

| 红线 | 为什么禁止 | 正确做法 |
|---|---|---|
| 大卡片 + 大留白（一屏放两三个模块） | 信息量不足，用户要滚动才能工作 | 密集排布，一屏承载完整任务 |
| 大按钮、大圆角、装饰性插画 | 降低单屏容量，无业务价值 | 按钮高 32（`bepButton` 默认），圆角 r=4 |
| 一屏只做一件事、强引导式步骤 | 后台是效率工具，不是营销页 | 同屏提供完整上下文（列表 + 筛选 + 批量） |
| C 端式空状态情绪化文案 | 干扰判断 | 说明情况 + 给出口 |
| 为美观牺牲可读性的低对比文字 | 长时间作业易疲劳 | 遵守 T85/T65/T45/T25 透明度体系 |

## 二、信息密度基线

### 布局常量（引用真源，不得自创）

| 项 | 值 | 来源 |
|---|---|---|
| 画布 | 1440 × 900 | `design-tokens.md` |
| 侧边栏 | 208 | 同上 |
| 页头 | 96（TopBar 48 + TitleBar/Tabs 48） | 同上 |
| 内容外边距 | 16 | 同上 |
| 卡片内边距 | 24 | 同上 |
| 表格宽 | 1152（1440 标准页） | 实际按屏幕计算 |
| 行高 | 48（密集场景可用 mini） | 同上 |

### 密度自检（每页必须通过）

| 检查 | 下限 |
|---|---|
| 折叠筛选态下表格可见行数 | ≥10 行 |
| 展开筛选态下表格可见行数 | ≥8 行 |
| 列表页首屏可见的完整任务链 | 筛选 + 操作 + 表格 + 分页 全在首屏，不需横向滚动找主按钮 |
| 表单页单列/双列 | 1440 页双列（`LABEL_W=90` + `FIELD_GAP=20`）；抽屉内单列 |
| 详情页每屏描述项 | ≥9 项（3 列 × 3 行） |
| 看板首屏 | 指标摘要 + 至少 1 个主图表，不出现「首屏只有标题和两张卡」 |

**若达不到**：优先压缩留白与分组间距，禁止通过缩小字号（正文 14 是下限，辅助 12 为特殊用途）来腾空间。

## 三、字体与层级

```
标题：16 / 24  Medium      —— 页面标题、分组标题
正文：14 / 22  Regular     —— 表格数据、表单值
辅助：12 / 20  Regular     —— 说明、单位、次要信息
极弱：7 / 10   Regular     —— 侧边栏副标题等特殊场景
```

- 层级靠**透明度**（T85 / T65 / T45 / T25）区分，不靠字号差异堆叠。
- 一个页面最多三级文字层级；出现第四级说明分组过深。
- 语义色仅用于：链接、状态、风险、禁用、辅助说明（沿用 `SKILL.md` 字段与颜色规则）。

---

## 四、间距语义

| 间距 | 用途 |
|---|---|
| 8 | 同组控件之间（标签↔控件 12、按钮组 8） |
| 16 | 模块之间（筛选区↔工具栏 24、工具栏↔表格 16、表格↔分页 16） |
| 24 | 分组标题上方、卡片内边距 |

**规则**：间距只表达「层级关系」，不用于制造视觉节奏。同一层级的模块间距必须一致。

## 五、操作距离（效率核心）

| 场景 | 要求 |
|---|---|
| 主操作 | 页面右侧固定位置（工具栏右对齐 / 底部吸底），一屏内可触达 |
| 批量操作 | 工具栏左侧；未选中禁用，选中显示条数 |
| 行内操作 | 操作列冻结在右侧；≤3 个直接显示，超出收进 ⋮ |
| 筛选后操作 | 筛选区与表格之间不放其它内容，避免视线跳跃 |
| 跨行对照 | 需要对照两行数据时提供冻结列 + 合计行，不要求用户滚动记忆 |
| 键盘 | 高频系统（录入、客服、审批）应支持 Tab 顺序合理、Enter 提交 |

**点击成本判据**：高频任务（每天多次）主路径 ≤3 次点击完成；超过则考虑行内操作、批量或保存视图。

## 六、效率能力清单

按数据量与频率判断是否需要：

| 能力 | 出现条件 |
|---|---|
| 搜索 | 列表数据 >50 条 |
| 筛选 | 需要按维度定位（几乎总是需要）；高频条件常驻 |
| 批量操作 | 存在重复性动作（推送、导出、审批、删除） |
| 导入 / 导出 | 数据量大或需离线核对 |
| 保存视图 | 数据量 >1 万，或用户有固定查询习惯 |
| 列配置 | 列数 >8 且不同角色关注列不同 |
| 合计行 | 含金额 / 数量列 |
| 快捷筛选条 | 状态为高频维度时，用具名状态 + 计数的快捷条，不用下拉 |
| 全局搜索 | 跨模块定位（编号 / 名称 / 供应商），结果按对象与单据分组 |

## 七、多任务处理

后台用户常同时处理多件事，必须支持上下文保持：

- **系统打开机制**：多任务型系统用 `TopBar + PageTabs`（可多开、可切换）；下钻型系统用 `TopBar + Breadcrumb`。同一系统不混用（沿用 `SKILL.md` 页头系统模式）。
- **返回保留上下文**：返回列表时必须保留筛选条件、排序、分页位置、滚动位置。
- **侧滑不丢页面**：抽屉用于「边看列表边改」，关闭后列表状态不变。
- **页签管理**：页签过多时应可关闭全部 / 关闭其它；页签名要有业务含义（禁止只显示编号）。
- **操作不打断扫读**：轻量成功提示用 `bepMessage`，不用弹窗打断。

## 八、大数据量处理

| 数据量 | 处理 |
|---|---|
| <1000 | 常规分页 |
| 1000–10 万 | 分页 + 每页条数（20/50/100）+ 跳页；提供导出 |
| >10 万 | 分页 + 保存视图 + 合计行 + 强筛选；**禁止默认全量加载**；长编号必须完整显示（不截断） |

其它硬要求：

- 不可截断字段：单据编号、合同编号、纳税人识别号等唯一标识。
- 数值列右对齐；金额带千分位；含税/不含税标注清楚。
- 空值统一用 `-`，不留空白。
- 超宽表格：内容视窗 + 右冻结操作列（`BEP_SHADOW_FREEZE_RIGHT`）。

---

## 九、留白与呼吸感（不是越多越好）

- 分组之间用**间距 + 分组标题**区分，不靠大色块。
- 卡片内边距固定 24，不因内容多少而变化。
- 表格行高固定 48（密集表格使用 mini），不为了「透气」加高行。
- 详情页的描述列表按 3 列铺满可用宽度，不允许大片右侧空白。

---

## 十、自检清单

- [ ] 首屏能完成一条完整任务（或至少完成主路径的前两步）
- [ ] 折叠态表格可见 ≥10 行
- [ ] 主操作一屏内可触达，无需滚动
- [ ] 正文未小于 14，辅助文字仅用于次要信息
- [ ] 数值列右对齐、金额千分位、唯一标识不截断
- [ ] 未出现 C 端式大留白（单模块占满一屏且无业务理由）
- [ ] 返回来源页保留筛选与位置
- [ ] 大数据量页面有明确的加载策略与保存视图判断
