# BeP 内置 RAG 参考层

> 本目录是 BeP skill 的检索型参考层。它帮助查找相似页面、Figma 真源摘要、业务组织案例和常见判断，但不替代 BeP 规范。

---

## 使用边界

- RAG 只做检索和参考，不做最终裁决。
- 最终裁决顺序：`SKILL.md` 铁律 > 组件文档 > `scripts/bep-components.js` > 校验器 > RAG 参考。
- RAG 与规范冲突时，以规范、组件库和校验器为准，并在交付说明中提示冲突。
- 历史页面只参考业务字段、信息分组、页面类型，不得照抄旧布局、旧坐标、旧组件写法。
- RAG 中出现的新模式必须先沉淀为正式规则或组件实现，才能用于后续页面生成。

---

## 检索流程

1. 先判断页面类型：列表页、详情页、表单页、弹窗、抽屉、提示、树表格或高级表格。
2. 读取正式规范：`SKILL.md`、`page-templates.md` 和相关组件文档。
3. 根据关键词读取 RAG 索引：
   - 查页面类型和业务案例：`page-cases.md`
   - 查真源摘要和样例来源：`source-index.md`
4. 用 RAG 辅助确认：
   - 页面结构是否接近既有案例
   - 字段分组亲近关系
   - Tabs 控制范围
   - 是否存在历史样例的旧规则风险
5. 写页面前回到正式规范确认组件入口和禁用项。
6. 构建并运行校验器；校验器失败时不得用 RAG 理由绕过。

## 常用检索关键词

| 需求关键词 | 优先读取 |
|---|---|
| 商品详情、对象详情、标题、操作按钮、商品信息、操作记录 | `page-cases.md` 的“商品详情页” |
| 描述列表、label/value、附件、图片、链接、标签 | `page-cases.md` 的“详情页描述列表” |
| 页头、面包屑、系统页签、页面打开方式 | `source-index.md` 的“页头与导航” |
| 表格、操作列、冻结列、树表格 | `source-index.md` 的“表格” |
| 表单、抽屉、弹窗、字段标题 | `source-index.md` 的“表单、弹窗、抽屉” |
