## 内容区卡片

```
OUTER_PAD = 16   // 主区域边缘 → 卡片
CARD_PAD  = 24   // 卡片内边距

卡片 x = 208 + 16 = 224
卡片 y = 96 + 16  = 112
卡片 w = 1232 - 16×2 = 1200
卡片 r = 4（页面级卡片）
卡片背景：白色
卡片投影：默认无阴影

注意：
- 页面级 Card 不加 `effects`
- 只有弹窗、抽屉、冻结列、悬浮层等特殊场景，或用户明确要求强调层级时，才允许显式添加阴影
- 不要把弹窗/浮层阴影复用到页面内容卡片上
```

## 表格列表页内部布局

```
TABLE_W = 1200 - 24×2 = 1152   // 卡片内可用宽

── 有筛选区 ──
筛选区 y     = CARD_PAD = 24              // 卡片内起点
筛选区 高     = 32（单行）/ 32+16+32=80（双行，行间距16）

工具栏 y     = 筛选区 y + 筛选区高 + 24   // 筛选区 → 工具栏：24px
工具栏 高     = 32

表格 y       = 工具栏 y + 32 + 16         // 工具栏 → 表格：16px

── 无筛选区 ──
表格 y = CARD_PAD = 24

── 表格结构 ──
表头：h = 48，背景 rgba(0,0,0,0.04)，底边 rgba(0,0,0,0.06)，无列竖线
数据行：h = 48，底边 rgba(0,0,0,0.06)，无斑马纹，内容不换行

── 列宽规则（所有基础表格/高级表格通用） ──
表格总宽由屏幕尺寸与页面布局计算；1440 宽标准页面中：
  TABLE_W = 1440 - 208 - 16×2 - 24×2 = 1152

建模方式：
  表格视觉上按行阅读，但设计实现必须按列建模。
  每一列必须有稳定的 label / width / align / render。
  同一列在表头与所有数据行中共享同一个 x、w、对齐方式和截断规则。
  不得按单行内容逐行摆放，避免列错位、数字不齐、操作区不齐和冻结列错位。

列宽审计：
  生成表格前必须输出/编写 COL_WIDTH_AUDIT。
  每列记录：表头、最长内容、计算宽、最终宽。
  审计结果必须和实际 cols 数组一致。

基础宽 = max(表头文字宽, 该列最宽数据宽) + 左16 + 右16

固定列：
  Checkbox 列固定 48。

内容测量列（默认不参与弹性，不使用固定预设宽）：
  序号、编码/工号、日期、状态Tag、电话
  宽度 = max(表头文字宽, 该列最宽数据宽) + 32

  操作列：
  继承单元格左右内边距 16 + 16，是一个父级复合列
  最多显示 3 个操作；超过 3 个时第 3 个变为更多
  操作列是一个复合单元格，不是多个独立表格列
  子级列按第1/2/3位操作分别统计实际数据最大宽度
  父级列内容宽 = 子级列宽之和 + 子级间距 16
  操作列宽 = bepActionMetrics(actionRows).width + 32
  单行渲染 = bepActionCell(actions, {slotWidths: metrics.slotWidths})
  例：16 + slot1(查看/编辑最大宽) + 16 + slot2(下架/删除最大宽) + 16 + slot3(更多/下发门店最大宽) + 16
  操作列文本不得换行、不得省略

弹性列（内容长度不定，平摊剩余空间）：
  姓名、部门、职位、地址、备注等

分配方式：
  1. Checkbox、内容测量列、操作列先按规则算出宽度，累加得 fixedSum
  2. 弹性列按基础宽累加得 elasticBaseSum
  3. 弹性列平摊剩余：extra = (TABLE_W - fixedSum - elasticBaseSum) ÷ 弹性列数
  3. 各弹性列最终宽 = 基础宽 + extra

  表格文字规则：
  表格单元格渲染统一使用 bepTableText / bepTruncText，maxW = col.w - 32
  默认列宽由最宽文本反推；正常情况下不应发生视觉截断
  地址/备注等特殊列：最多显示15个字，超出省略（先截为15字再传入 bepTableText / bepTruncText）
  编号、日期、电话、关键编码等不可截断字段：按完整文本反推列宽，渲染时可传 truncate:false
  操作列：不得换行、不得省略，必须通过操作列自适应宽度解决

超宽冻结规则：
  表格总宽 > TABLE_W 时，冻结操作列（右侧），拆成内容视窗 + 冻结操作列
  右侧冻结列加 BEP_SHADOW_FREEZE_RIGHT 阴影（阴影落在左侧）
  左侧冻结列加 BEP_SHADOW_FREEZE_LEFT 阴影（阴影落在右侧）

非横向滚动表格填充规则：
  只要表格不是明确的横向滚动/冻结列表格，最终表格宽度必须等于内容区宽度（TABLE_W 或 CONTENT_W）。
  不得让 tableW 仅等于所有列自然宽度之和后停在左侧。
  如果列宽总和小于内容区宽度，必须把剩余宽度分配给 grow:true 的弹性列：
    baseTableW = sum(col.w)
    if baseTableW < CONTENT_W:
      extra = CONTENT_W - baseTableW
      按 grow 列数量或权重分配 extra
      finalTableW = CONTENT_W
    else:
      finalTableW = baseTableW
  详情页 SKU 表、日志表、明细表等普通表格默认属于非横向滚动表格，必须横向填满内容区。
  只有当 finalTableW > CONTENT_W 且业务需要保留完整列宽时，才进入横向滚动/冻结列规则。

严格要求：
  表格规则必须严格遵守；单元格内容无特殊要求不得换行。
  数值列使用 bepTableText / bepTruncText 时必须传 alignH:'RIGHT'，并按最宽完整数值反推列宽。
  交付前必须检查：长编号完整、数值右对齐、操作列不截断、冻结阴影方向正确、非横向滚动表格填满内容区。

── 分页器 ──
分页器 y = 表格 y + 48 + 数据行数×48 + 16
```

## 页面高度反推规则

页面根容器可以以 1440×900 为默认画布，但内容高度不得被根容器裁切。

只要页面内容高度由脚本计算（例如 `cy` 累加、`card.resize(...)`、详情页描述列表、表格明细、表单区块），生成末尾必须由内容反推根容器高度：

```javascript
card.resize(card.width, cy);
pageFrame.resize(CANVAS_W, Math.max(CANVAS_H, card.y + card.height + OUTER_PAD));
```

规则：
- `pageFrame` 若设置 `clip:true`，必须保证 `pageFrame.height >= 内容最底部 + OUTER_PAD`。
- 详情页、表单页、带明细表页面通常会超过 900px，不得固定 `CANVAS_H` 后不 resize。
- 交付前必须检查：`card.y + card.height + OUTER_PAD <= pageFrame.height`。
- 如果有多个内容卡片，使用所有内容区块的最大底部值反推：`maxBottom = Math.max(card1.y + card1.height, card2.y + card2.height, ...)`。

## 弹窗（Modal）

```
宽度规格（Figma实测）：
  小：420px（简单确认、简短表单）
  中：640px（默认，普通表单）
  大：800px（复杂表单，2列布局，最高610px）

垂直定位：
  高度 ≤ 630px → 垂直居中
  高度 > 630px → 距顶部 15%（900×15%=135px）

结构（上到下）：
  标题栏    h=56    白色，底部分割线 1px 黑色 10% 包含在标题栏内
  内容区    上下左右各 24px padding
  底部按钮  h=52    showFooter=true 时显示，取消+确定，右对齐，间距 8px

弹窗垂直居中于 1440×900 画布
遮罩：rgba(0,0,0,0.45) 覆盖全画布
```

## 抽屉（Drawer）

```
宽度规格：
  小：420px（轻量确认、短表单）
  中：640px（默认，新增/编辑表单）
  大：800px（详情查看、复杂内容）

结构（上到下）：
  标题栏    h=56    底部分割线 1px 黑色 10% 包含在标题栏内
  内容区    上下左右各 24px padding；内容起点 y=80
  底部按钮  h=52    showFooter=true 时显示，取消+确定，右对齐，右边距16，间距 8px

抽屉从画布右侧滑入（x = CANVAS_W - DRW_W）
高度 = CANVAS_H；长内容不拉高抽屉，表现为内容区滚动
完整遮罩：rgba(0,0,0,0.45)
表单抽屉：variant='form'，默认显示底部按钮
详情抽屉：variant='detail'，默认不显示底部按钮，只保留右上关闭
面板阴影：沿用抽屉 Figma 真源三层 Drop Shadow
```
