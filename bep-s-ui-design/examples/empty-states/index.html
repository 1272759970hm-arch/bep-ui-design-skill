BEP-S 空状态（缺省页）规格与用法

版本 2026-11-05 ｜ 依据：组件库画板 138:3955「35空状态」Dev Mode 实测
关于"放哪、怎么调用"的结论：缺省页源文件留在 Figma 即可，不需要上传第三方网站。 HTML 原型不能直接外链 Figma 图片（链接带登录态、会过期、file:// 下也打不开）， 正确做法是把插画导出成 PNG → base64 内嵌进单文件 HTML——本页三张插画就是刚从你选中的画板 (138:3955) 直接导出并内嵌的，全程不经过任何图床。

01规格实测（375 屏内）

插画 225×195 居中；插画底 → 16px → 标题 → 8px → 描述；有操作时按钮在描述下 16px。

部分规格
插画225 × 195 px，位图 instance，8 个场景各一张，不许一图套全部
标题16px / Medium(500) / lh24 / 深色档（截图近 #22262F，registry 旧记 #444F60 待核）
描述14px / lh24 / #9199A2，最多两行
间距插画→标题 16；标题→描述 8；描述→按钮 16
底色不铺灰底，直接放在页面底色 #F7F8FA 上

03HTML 结构（复制即用）

插画 src 换成你自己的 base64 串；别外链任何 URL。

<div class="empty">
  <img src="data:image/png;base64,..." alt="">   <!-- 225×195，导出自 Figma -->
  <div class="t">暂无已完成工单</div>            <!-- 16px/500，上边距16 -->
  <div class="d">切换上方筛选查看其他状态的工单</div> <!-- 14px #9199A2，上边距8 -->
  <button class="btn">去处理</button>            <!-- 可选，上边距16 -->
</div>
